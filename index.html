用 Racket 学 OpenGL

这套教程按 learnopengl 的节奏讲 OpenGL，代码全部用 Racket 写，GLSL 用 racket-shader 这个 DSL 写成 S 表达式。

每节课就是一个目录：一页 HTML 教程，加一份可以直接 racket 跑起来的源码。

开始之前

  • Racket v8 或更新（作者实测 v9.3 [cs]，Linux）。
  • 安装两个包：raco pkg install racket-shader racket-shader-opengl（跟源码改时用 --link <源码目录>）。racket-shader 提供 #lang glsl 与 (glsl ...) 宏（集合名是 glsl），racket-shader-opengl 提供 #lang glsl-opengl 并叠加 gl-* 与编译/链接；教程用后者。依赖 opengl 和 gui-lib 会自动装上。
    包名 ≠ 语言名：raco pkg 认的是 racket-shader / racket-shader-opengl，#lang 认的是集合名 glsl / glsl-opengl。
  • 能开图形窗口：Linux 下要有 DISPLAY，WSL 需要 WSLg。

装好之后先跑第 0 课（不开窗口，只在终端打印课程顺序）：

$ racket 00-intro/intro.rkt

阅读节奏：02 会先解释 lib/window.rkt，再把 raw OpenGL 的编译/缓冲/VAO 流程走一遍，然后才介绍 build-program / buffer-new 这些便利层；09 会把顶点布局和 uniform setter 的裸写法再展开一次；13 拆开「文字 → 纹理 → 3D quad」，14 再把「文件 → 顶点/索引 → VBO/EBO」走一遍，15 把精灵图、billboard 和 HD 场景组合成一个完整画面。正式章节讲 API 和用例，复习章节（R1–R4）再把 API 与「计算放在哪」重新对齐；R4 会用 CPU 把 14 课的茶壶完整画一遍。便利层只是「少写、防错」，不是 OpenGL 的新规则。

最短路线：00 → 01 → 02 → 03 → 04 先把 2D 画出来；05 → 06 → 07 进 3D；08 → 09 → 10 → 11 → 12 学光照；13 / 14 / 15 是额外主题；15 是把前面内容拼成一个 HD 场景，可以最后做。每段结束做对应复习（04 后 R1、07 后 R2、11 后 R3、14 后 R4）。

渲染管线

后面这几节课讲的其实就是这一条主线：CPU 端把顶点数据准备好，剩下的都交给 GPU。

关键点方括号里那两段是你写的程序，叫 shader，用 GLSL 写；其余阶段是 GPU 固定行为，只能设参数不能改代码。

命名约定

代码里出现的名字分三类，认清了读起来就不会卡住。

名字 来自哪里 说明
gl-array-buffer OpenGL 内置常量的 Racket 改名 C 里写 GL_ARRAY_BUFFER，这个名字不是作者起的
vec-3 mat-4 shader-byte-size build-program racket-shader + racket-shader-opengl DSL 提供的类型和函数（build-program 在 OpenGL 层）
vertices program vao draw init 教程自己起的 读代码时可以先只看这些

教程里的 shader 和 Racket 代码统一使用 Racket 风格的 kebab-case：gl-position、frag-color、u-model、vec-3、mat-4。racket-shader 在生成 GLSL 时会把它们换成真正的 GLSL 拼写：gl_Position、frag_color、u_model、vec3、mat4。

别把 vec-3 当成 racket/mathvec-3 / vec-4 / mat-4 / vx / vdot 全部来自 #lang glsl（racket-shader），racket/math 只提供 degrees->radians 这类数学函数。(require racket/math) 不会给你 vec-3。
另外，带连字符的是你写的 Racket 名字；不带连字符的 vec3 / mat4 是生成后的 GLSL 文本。DSL 也接受 vec3，但本教程统一写 vec-3，看到 vec3 就知道那段是 GLSL 原文。

关键点#lang glsl-opengl 就是一个普通的 Racket 模块，只是预先 require 好了 GLSL 全套 + OpenGL 层，所以在文件顶部写 #lang glsl-opengl 就能直接用 glsl / vec-3 / gl-* / buffer-new。
只写 GLSL、不碰 OpenGL 时用 #lang glsl（不拉进 opengl）。

参考与取舍

这套教程不是从零发明讲法。主骨架来自 learnopengl，另外几份参考分别补它讲得不够简、或 API 查起来不方便的地方。读的时候可以交叉对照，但不要同时啃三份教程。

参考用来对照什么本教程怎么取舍
learnopengl / 中文版 章节顺序、每个效果的完整做法 保留 Getting started → Lighting → Model loading 的主线；把 C++/GLFW 换成 Racket/GUI，把 raw GL 和便利层分开讲
docs.gl 单个 GL 函数的签名、参数、常量 不抄 API 大全；遇到没展开的函数，按 02 的命名规则查
WebGL Fundamentals 管线、状态、坐标变换的直观解释 借用「先讲数据流、再讲 API」的讲法；不引入 WebGL/JS 细节
tinyrenderer 不用 GPU 时，光栅化、深度、纹理到底在算什么 只在 R1–R4 的 CPU 对照里用这个视角，不把教程变成软件渲染器
OGLdev look-at、投影、法线矩阵的推导 保留推导，但把矩阵约定和 Racket 代码对齐

排错速查

新手最常遇到的不是「公式不会」，而是「窗口开了但什么都没有」。先按症状查这张表，再回去看对应章节。

症状先查什么常见原因
窗口不出现 / 一启动就退出 DISPLAY、WSLg、终端报错 没有图形环境；Racket/GUI 依赖没装好；程序在 show 之前就抛异常
窗口在，但只有清屏色 shader 编译/链接日志、program-use、gl-bind-vertex-array、draw 数量 shader 没编译过；VAO 没绑；属性槽没 enable；顶点数或索引数写错
三角形/立方体整个消失 顶点坐标、w、投影矩阵、背面剔除 坐标超出裁剪范围；w 写错；近/远平面把物体裁掉；绕序和剔除方向相反
3D 遮挡关系不对 gl-depth-test、清屏掩码 没开深度测试；清屏只擦了颜色没擦深度；深度比较函数设反
纹理全黑 / 全白 mipmap、纹理单元、sampler uniform、UV 用了 mipmap 过滤却没 gl-generate-mipmap；没 gl-active-texture 就绑纹理；sampler 没指向正确单元
光照一块黑一块亮，方向不对 法线、normal matrix、l 的方向、1.0 字面量 法线没归一化；非等比缩放没用逆转置；lightPos - fragPos 写成反方向；GLSL 里写了 1 而不是 1.0
相机一转就崩 / 画面 NaN look-at 的 up、pitch 钳制 forward 与 up 平行，叉乘得零向量；pitch 到了 ±90°
点 X 窗口关了，进程还在 on-close 默认只隐藏窗口；需要派生 frame% 并 (exit 0)（01 课）

接下来学什么

本教程停在「能加载模型、能算 Phong 光照，并把精灵图、billboard 和混合组成一个 HD 场景」。再往下走，建议一次只加一个目标，不要把新概念堆在一起：

  • Framebuffer / render-to-texture：把场景画到一张纹理，再做后处理、阴影贴图、反射。这是很多高级效果的地基。
  • Shadow mapping：从光源视角画一遍深度，再从相机视角比较。先理解深度纹理，再写代码。
  • Normal mapping / PBR：前者让平面假装有凹凸，后者换掉 Phong 的经验公式。都需要先熟悉切线空间和纹理采样。
  • Instancing：同一份顶点画成千上万个物体，减少 draw call。
  • MSAA / gamma / HDR：画面「有锯齿」「颜色发灰」「高光死白」时再学，效果立竿见影。
  • Compute shader：通用并行计算，和图形管线是另一条线。

对应 learnopengl 的 Advanced 部分。建议每学一个，都回到本教程的 R1–R4 复习页问一遍：这个公式在哪算、数据怎么流、CPU 版长什么样。
