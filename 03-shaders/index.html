着色器

本节目标：一个程序里讲清四件事——GLSL 有哪些类型、两段着色器之间怎么传值、uniform 怎么从 CPU 送进来、一个顶点怎么带多个属性。跑起来应该看到三角形三个角分别是红、绿、蓝，中间自动渐变，整体亮度随时间脉动。

$ racket 03-shaders/shaders.rkt

计算位置顶点变换与颜色输出在 GPU 的两段 shader；u-time 由 CPU 每帧算好并上传。CPU 也能做同样的插值和乘法，但「按三角形覆盖的像素逐个插值」正是光栅化硬件的工作。数据流：CPU → uniform → 顶点着色器 → varying → 片元着色器 → 屏幕。

3.1 GLSL 的类型

GLSL 的类型就三类，够用了：

  • 标量：float、int、bool；
  • 向量：vec-2、vec-3、vec-4；
  • 矩阵：mat-2、mat-3、mat-4。

最容易踩的一条：浮点字面量必须写 1.0，不能写 1。GLSL 不做隐式整浮转换，1 是 int，跟 float 混用编不过。所以位置、比例、颜色分量，一律写 1.0、0.5 这种带小数点的形式。

向量可以整体做算术（逐分量进行），也可以用 swizzle 取分量、重排、拼新向量：

示例（不是本课源码）：一个片元着色器里塞进标量和向量
(glsl (version 330 core)
      (out vec-4 frag-color)
      (define (main) void
        ;; 标量：float / int / bool。浮点字面量必须写 1.0——写 1 是 int。
        (float a 1.0)
        ;; 向量：vec-2 / vec-3 / vec-4。整个向量可以一起算，逐分量进行。
        (vec-3 c (* (vec-3 1.0 0.5 0.2) 0.5))
        ;; swizzle：取分量、重排、拼新向量。
        (set! frag-color (vec-4 (z c) (x c) (y c) a))))

(z c) 翻译出来是 c.z，(xy c) 是 c.xy；上面最后一行会变成 frag-color = vec-4(c.z, c.x, c.y, a);。想取哪几个分量、按什么顺序拼，都写在括号里。

3.2 (glsl …) 宏：S 表达式就是 GLSL

racket-shader 的 glsl 是个宏：编译期把 S 表达式翻译成 GLSL 文本。规则很薄——括号就是调用，(set! x v) 是赋值，(define (main) void …) 是函数定义，(layout (location 0) in vec-2 a-pos) 这种声明同样写成括号。

本课顶点着色器在 shaders.rkt 里是这样写的：

03-shaders/shaders.rkt：vert-src（S 表达式）源码 ↗
(define vert-src
  (glsl (version 330 core)
        (layout (location 0) in vec-2 a-pos)
        (layout (location 1) in vec-3 a-color)
        ;; out：交给片元着色器。名字和类型要和那边的 in 一致，两段靠这个配对。
        (out vec-3 v-color)
        (define (main) void
          (set! gl-position (vec-4 a-pos 0.0 1.0))
          (set! v-color a-color))))       ; 原样交出去

把 (displayln (glsl-program-src vert-src)) 加进文件跑一遍，就能看到 GPU 真正收到的那段文本：

glsl-program-src 的输出：真正的 GLSL 文本
#version 330 core
layout(location = 0) in vec2 a_pos;
layout(location = 1) in vec3 a_color;
out vec3 v_color;
void main() {
  gl_Position = vec4(a_pos, 0.0, 1.0);
  v_color = a_color;
}

关键点着色器编译报错时，报的行号是上面那份 GLSL 文本的行号，不是 S 表达式里的行号。找错时把它当「编译产物」看、对着它数行；S 表达式里那几行是 Racket 注释，翻译后不会留下。

3.3 in / out：阶段间传值与插值

顶点着色器算完位置，还要把每个顶点的颜色交给片元着色器。交接靠一对 out / in：顶点着色器里声明 (out vec-3 v-color)，片元着色器里声明 (in vec-3 v-color)——名字和类型对上，值就传过去了。两段代码里相关的就是这几行：

03-shaders/shaders.rkt：顶点着色器的 out源码 ↗
        ;; out：交给片元着色器。名字和类型要和那边的 in 一致，两段靠这个配对。
        (out vec-3 v-color)
03-shaders/shaders.rkt：片元着色器的 in源码 ↗
(define frag-src
  (glsl (version 330 core)
        (in vec-3 v-color)
        (uniform float u-time)
        (out vec-4 frag-color)
        (define (main) void
          (float k (+ 0.5 (* 0.5 (sin u-time))))   ; sin 在 -1..1 → 变换成 0.5..1.0
          (set! frag-color (vec-4 (* v-color k) 1.0)))))

关键现象在片元这一侧：v-color 拿到的不是「某一个顶点的颜色」，而是插值后的颜色。三个顶点分别给红、绿、蓝，三角形内部就自动渐变——混合代码一行都不用写。

这一步的算法是：光栅化阶段算出每个像素到三个顶点的距离权重（重心坐标），再按权重把三个顶点的 v-color 混起来。所以渐变是 GPU 免费送的，我们只负责在每个顶点上给出端点值。

3.4 uniform：整次绘制共用一份

uniform 是第三种输入：它不属于任何顶点，一次 draw 调用里所有顶点、所有像素看到的是同一份值。CPU 每帧更新它，就能做出脉动、旋转这类整体变化。本课用它做亮度脉动：(uniform float u-time)。

先看 raw 版：uniform 在 GL 里是「先查位置，再按类型调用对应的 gl-uniform-*」。

raw OpenGL：uniform 的两步
;; 链接后查一次：名字必须是真正的 GLSL 名 u_time
(define loc (gl-get-uniform-location program "u_time"))

;; 每帧上传：float 用 gl-uniform-1f；vec3 是 gl-uniform-3f；mat4 是 gl-uniform-matrix-4fv
(gl-use-program program)          ; uniform 作用在「当前 program」上
(gl-uniform-1f loc t)

本课从 02 的 raw 流程继续往前走，开始用两个便利层：uniform-location 只是 gl-get-uniform-location 的短名字；uniform-set! 则把「按类型选 gl-uniform-*、拆分量、校验长度」收进一个函数。用之前先知道它们背后是什么。

用 uniform 有三个要点：

  1. 位置查一次就存起来：uniform-location 在 program 链接好之后查，返回一个整数位置；找不到时返回 -1。
  2. 上传必须在 program-use 之后：uniform 上传作用在「当前程序」上，不是作用在某个 program 对象上。
  3. 类型写在参数里：(uniform-set! loc 'float t) 上传 1 个 float，'int 是 int，'vec-3 / 'vec-4 是 3 / 4 个 float，'mat-4 是 mat-4。uniform-set! 按类型符号自动选对底层的 gl-uniform-*；裸写法就是 (gl-uniform-1f loc t)（'vec-3→gl-uniform-3f、'mat-4→(gl-uniform-matrix-4fv loc 1 #f m)）。

init 里查位置（本课存进 u-time-loc，每帧直接用）：

03-shaders/shaders.rkt：init 的末尾源码 ↗
  (gl-bind-vertex-array 0)

  ;; uniform 的位置在链接后查一次、存起来。找不到会返回 -1。
  (set! u-time-loc (uniform-location program "u_time")))

draw 里上传：

03-shaders/shaders.rkt：draw 里每帧上传源码 ↗
  (program-use program)
  ;; 上传 uniform：必须在 program-use 之后，因为它作用在"当前程序"上。
  ;; uniform-set! 按类型符号自动选对 gl-uniform-*（'float→1f、'vec-3→3f、'mat-4→matrix-4fv）。
  (uniform-set! u-time-loc 'float t)

坑在 program-use 之前上传 uniform，会作用到当时绑着的那个程序上。这是静默错误：不报错、也不生效，画面看着就是「没变化」，只能回头查顺序。

3.5 多属性与交错布局

上一课一个顶点只有位置。本课每个顶点是位置 vec-2 + 颜色 vec-3，两样交错排在同一条缓冲里，一个顶点接着一个顶点：

x y r g b | x y r g b | x y r g b

交错布局要给 gl-vertex-attrib-pointer 两个数：步长（相邻两个顶点隔多少字节）和偏移（这个属性要从顶点开头跳过多少字节）。这两个数现在不写字面量，直接从布局算出来：

03-shaders/shaders.rkt：步长与偏移源码 ↗
  ;; 步长 = 一个顶点占多少字节；偏移 = 这个属性前面要跳过多少字节。
  ;; 两个数都从布局算出来，不写字面量：以后把位置换成 vec-3，下面自动跟着对。
  (define stride (shader-stride-bytes 'vec-2 'vec-3))   ; 2 + 3 = 5 个 float = 20 字节
  (define color-offset (shader-byte-size 'vec-2))      ; 跳过位置那 2 个 float = 8 字节
  (gl-vertex-attrib-pointer 0 2 gl-float #f stride 0)
  (gl-enable-vertex-attrib-array 0)
  (gl-vertex-attrib-pointer 1 3 gl-float #f stride color-offset)
  (gl-enable-vertex-attrib-array 1)

(shader-stride-bytes 'vec-2 'vec-3) 把参数里的类型依次加起来：2 + 3 = 5 个 float = 20 字节。(shader-byte-size 'vec-2) 只算一个类型：2 个 float = 8 字节。好处是布局和读数用的是同一份事实——以后把位置换成 vec-3，把两个参数改成 'vec-3 'vec-3 和 'vec-3，步长和偏移自动跟着对，不会出现「改了数据忘了改魔数」造成的整体错位。

关键点已实测 (shader-stride-bytes 'vec-2 'vec-3) 得到 20、(shader-byte-size 'vec-2) 得到 8，和手写字面量结果相同。用函数算不是为了省打字，是为了让步长、偏移和布局描述不会各说各话。

完整代码

03-shaders/shaders.rkt，本课全部代码（直接 racket 跑）：

03-shaders/shaders.rkt源码 ↗
#lang glsl-opengl
;; ============================================================
;; 03 · 着色器：类型、阶段间传值、uniform、多属性
;; 运行：racket 03-shaders/shaders.rkt
;; 上一课：02-hello-triangle/rectangle.rkt
;; ============================================================
;; 效果：三角形三个角红/绿/蓝，中间自动渐变，整体亮度随时间脉动。
;; 四件事都在这一个程序里：GLSL 类型、out→in 传值、uniform、多个顶点属性。

(require racket/class
         racket/gui
         "../lib/window.rkt"
         "../lib/gpu.rkt")

;; 顶点着色器。
;; GLSL 的类型：float/int/bool 是标量，vec-2/vec-3/vec-4 是向量（浮点字面量要写 1.0）。
;; 这里有两个输入属性：位置 a-pos（0 号槽）、颜色 a-color（1 号槽）。
(define vert-src
  (glsl (version 330 core)
        (layout (location 0) in vec-2 a-pos)
        (layout (location 1) in vec-3 a-color)
        ;; out：交给片元着色器。名字和类型要和那边的 in 一致，两段靠这个配对。
        (out vec-3 v-color)
        (define (main) void
          (set! gl-position (vec-4 a-pos 0.0 1.0))
          (set! v-color a-color))))       ; 原样交出去

;; 片元着色器。
;; v-color 拿到的是"插值后"的颜色：三个顶点分别红/绿/蓝，GPU 按距离混合，
;; 于是三角形中间自动渐变——混合代码一行都不用写。
;; u-time 是 uniform：整个绘制共用一份，由 CPU 每帧更新（这里用来做亮度脉动）。
(define frag-src
  (glsl (version 330 core)
        (in vec-3 v-color)
        (uniform float u-time)
        (out vec-4 frag-color)
        (define (main) void
          (float k (+ 0.5 (* 0.5 (sin u-time))))   ; sin 在 -1..1 → 变换成 0.5..1.0
          (set! frag-color (vec-4 (* v-color k) 1.0)))))

;; 03 开始使用 uniform 便利层：uniform-location 查位置，uniform-set! 按类型上传。
;; 对应的 raw 两步（gl-get-uniform-location + gl-uniform-*）见教程 3.4。
;;
;; 顶点数据：每个顶点 = 位置(vec-2) + 颜色(vec-3)，交错排成一条：
;;   x y r g b | x y r g b | x y r g b
(define vertex-data
  (concat-vecs (vec-2 -0.6 -0.5) (vec-3 1.0 0.0 0.0)    ; 红
               (vec-2  0.6 -0.5) (vec-3 0.0 1.0 0.0)    ; 绿
               (vec-2  0.0  0.6) (vec-3 0.0 0.0 1.0)))  ; 蓝

(define program #f)
(define vao #f)
(define u-time-loc #f)

(define (init)
  (set! program (own! 'program (build-program (gl-vertex-shader vert-src)
                                              (gl-fragment-shader frag-src))))

  (set! vao (own! 'vertex-array (vertex-array-new)))
  (gl-bind-vertex-array vao)
  (define vbo (own! 'buffer (buffer-new)))
  (gl-bind-buffer gl-array-buffer vbo)
  (buffer-upload gl-array-buffer vertex-data gl-static-draw)

  ;; 步长 = 一个顶点占多少字节；偏移 = 这个属性前面要跳过多少字节。
  ;; 两个数都从布局算出来，不写字面量：以后把位置换成 vec-3，下面自动跟着对。
  (define stride (shader-stride-bytes 'vec-2 'vec-3))   ; 2 + 3 = 5 个 float = 20 字节
  (define color-offset (shader-byte-size 'vec-2))      ; 跳过位置那 2 个 float = 8 字节
  (gl-vertex-attrib-pointer 0 2 gl-float #f stride 0)
  (gl-enable-vertex-attrib-array 0)
  (gl-vertex-attrib-pointer 1 3 gl-float #f stride color-offset)
  (gl-enable-vertex-attrib-array 1)

  (gl-bind-vertex-array 0)

  ;; uniform 的位置在链接后查一次、存起来。找不到会返回 -1。
  (set! u-time-loc (uniform-location program "u_time")))

(define (draw)
  (define t (/ (current-inexact-monotonic-milliseconds) 1000.0))

  (gl-clear-color 0.10 0.12 0.20 1.0)
  (gl-clear gl-color-buffer-bit)

  (program-use program)
  ;; 上传 uniform：必须在 program-use 之后，因为它作用在"当前程序"上。
  ;; uniform-set! 按类型符号自动选对 gl-uniform-*（'float→1f、'vec-3→3f、'mat-4→matrix-4fv）。
  ;; 裸写法： (gl-uniform-1f u-time-loc t)；uniform-set! 只是按类型符号帮你选函数。
  (uniform-set! u-time-loc 'float t)

  (gl-bind-vertex-array vao)
  (gl-draw-arrays gl-triangles 0 3)
  (gl-bind-vertex-array 0))

(define-values (frame canvas)
  (make-window #:title "03 着色器"
               #:init init
               #:draw draw
               #:on-close release-all!))
(send frame show #t)

;; uniform 每帧在变，需要定时器不断请求重绘
(define timer
  (new timer% [interval 16]
              [notify-callback (lambda () (send canvas refresh))]))

试试看

  1. 把片元着色器里的 k 换成 (* 0.5 (+ 1.0 (sin (* u-time 3.0))))：脉动变快（u-time 前面乘了 3）。
  2. 给顶点加第三个属性：用一个 float 控制每个顶点的亮度。要同时改三处——着色器里多一个 (layout (location 2) in float aBright)、vertex-data 里每个顶点多一个数、gl-vertex-attrib-pointer 里多描述一个槽（步长用 (shader-stride-bytes 'vec-2 'vec-3 'float) 重算，别手写）。
  3. 把 color-offset 故意写成 0：颜色会从位置那几个字节开始读，画面颜色错乱；改回来对比一下。
  4. 把 (set! v-color a-color) 换成 (set! v-color (vec-3 1.0 1.0 1.0))：渐变消失，三角形变成一片白（亮度脉动还在）。

GPU 资源本节代码里每个 *-new / build-program 都用 own! 登记，关窗时 release-all! 统一删除。为什么这些句柄 GC 管不了，见 02 · 2.9。

小结

概念 一句话
GLSL 类型 float/int/bool、vec-2/vec-3/vec-4、mat-2/mat-3/mat-4；浮点字面量一律写 1.0
glsl 宏 编译期把 S 表达式翻译成 GLSL 文本：括号即调用、set! 即赋值；用 glsl-program-src 能看到产物
in / out 与插值 顶点着色器的 out 与片元着色器的 in 按名字 + 类型配对；中间的值由光栅化阶段插值
uniform 整次绘制共用一份，由 CPU 上传；location 链接后查一次，上传要在 program-use 之后
交错布局 一个顶点 = 若干属性首尾相接；gl-vertex-attrib-pointer 的步长和偏移决定从缓冲的哪里切
shader-stride-bytes / shader-byte-size 从布局类型算出步长与偏移的字节数，替代手写魔数
