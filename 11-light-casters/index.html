光的种类

本节目标：光照那三项（ambient / diffuse / specular）从 09 课起没变过，这一节换的是「光从哪来」——同一套公式配三种光源：方向光（只有方向，没有位置）、点光（有位置，随距离衰减）、聚光（点光再加一个锥）。三个源码文件各跑一遍，每份只比上一份多几行，对着 diff 读就能看清每一种光是丢掉了什么、又加回了什么。跑起来应该看到三件事：方向光下四个立方体同朝向的面一样亮；点光下同样的四个立方体亮成四个档次；聚光下只有光锥里的立方体被照亮，锥外几乎全黑，锥边是软的。

$ racket 11-light-casters/directional.rkt
$ racket 11-light-casters/point.rkt
$ racket 11-light-casters/spot.rkt

计算位置方向光 / 点光 / 聚光的公式都在片元着色器里算；CPU 只上传光的位置、方向、颜色、衰减系数。CPU 也可以做逐顶点或预烘焙，但动态灯和逐像素高光更适合 GPU（见 R3）。

11.1 方向光：只有方向，没有位置

太阳离我们足够远，远到什么程度？远到「它在地球上的哪个点上方」这件事不再有意义——射到地面上的光线已经互相平行。光照公式里的 light-dir（从这一点指向光源的方向）在这种情况下整个场景共用一个值，不必再逐片元去减一个位置。

所以方向光这一份把 09 / 10 课的 u-light-pos 换成了 u-light-dir。注意名字里的 Dir 存的是光往哪走（传播方向），而公式要的是「从片元指向光源」，取反一下即可：

11-light-casters/directional.rkt：片元里唯一的改动——方向取反，不再碰 v-frag-pos源码 ↗
        (define (main) void
          (vec-3 norm (normalize v-normal))
          (vec-3 light-dir (normalize (- u-light-dir)))
          (float ambient 0.1)
          (float diff (max (dot norm light-dir) 0.0))
          (vec-3 reflect-dir (reflect (- light-dir) norm))
          (vec-3 view-dir (normalize (- u-view-pos v-frag-pos)))
          (float spec (* (pow (max (dot view-dir reflect-dir) 0.0) 32.0) 0.5))
          ;; 这里没有 attenuation：光走到哪儿都是同一个强度，距离不进公式。
          (set! frag-color (vec-4 (* (+ ambient diff spec) u-light-color u-object-color) 1.0)))))

跑起来画面里是四个立方体排成一列，一个比一个远。它们都只做了平移、没有旋转，所以「朝向同一个方向的面」在四处都存在——你会发现四个顶面亮得一模一样，前面和侧面也一样。距离这件事根本没进公式（diff 拿的是常量 light-dir，不是逐片元的减法结果），亮度只由「面朝哪」决定。

关键点方向光的「位置」不是省略了，而是推到了无穷远：位置一去，距离也就没有了分母，衰减无从谈起。11.2 的点光会把位置和衰减一起加回来，而两张画面用的是同一张位置表、同一台相机——对照着看，方向光丢掉的东西一目了然。

11.2 点光与衰减：位置回来了，亮度开始随距离掉

灯泡不是太阳：它就挂在房间里的某一点，光从这一点向四周辐射。于是 u-light-pos 回来了，light-dir 得逐片元算——每个像素看到的「灯的方向」都不一样。

接下来是新的东西：亮度会随距离下降。可以这么想：灯每秒送出固定的能量，这些能量摊在以灯为心、半径 d 的球面上，球面积是 4πd²——距离翻一倍，同样多的能量摊到四倍大的面积上，单位面积只剩四分之一。教科书式的写法是把这件事拆成三项：

先把点光的方向和距离写清楚：

l = normalize(lightPos - fragPos)　（从片元指向灯）

d = length(lightPos - fragPos)

如果只按物理上的「能量摊在球面上」，强度应该按 1 / d² 掉：距离翻倍，球面积变四倍，单位面积只剩四分之一。但纯 1/d² 在 d → 0 时会爆炸，而且艺术家通常想手动控制「这盏灯照多远、近处多亮」。所以实时渲染常用一个三项分母来近似：

attenuation = 1 / (kc + kl·d + kq·d²)

三个系数各管一段距离：

  • kc（常数项）：d = 0 时只剩它，所以它是贴灯时的保底，也是防止除零的闸；
  • kl·d（线性项）：控制中距离的衰减速度，把近段和远段接得平缓；
  • kq·d²（二次项）：远距离时占主导，接近物理的 1/d² 行为。

它不是物理定律，而是一个可调曲线：调大 kc 整体变暗但远段更均匀，调大 kq 光只能走几步。下面这档参数是本课用的。

本课这一档里 kc = 1.0：d 很小时分母几乎只剩它，所以它是贴灯时的保底——顺便也是防止近距离除零爆表的那道闸。接着 kq·d²（0.032d²）随着 d 平方增长，到 d ≈ 5.6 就反超了 kc，成为分母里最大的那一项，曲线的右半段因此几乎拉平（见图 11-1）。kl·d（0.09d）是中间那一项：它自己不常是最大的，但把前两段之间接得平缓，少掉它，曲线会在中段陡一下。下面这张表是几档常用的配法，d 一栏写的是「这组系数大致能把光送到多远」——到那一点时衰减都压到了 1% 左右，差别只在用多长的距离做到这件事：

想覆盖到距离 kc 常数 kl 线性 kq 二次 到那一点时的 attenuation
7 左右（近） 1.0 0.7 1.8 1 / (1 + 4.9 + 88.2) ≈ 0.011——二次项已经硬得离谱，光只能走几步
50 左右（中） 1.0 0.09 0.032 1 / (1 + 4.5 + 80) ≈ 0.012——本课用的就是这档
325 左右（远） 1.0 0.014 0.0007 1 / (1 + 4.55 + 73.9) ≈ 0.013——二次项几乎退休，靠常数与线性撑着

落到代码上，点光只比方向光多两行——算距离、算衰减——再把衰减乘到 diffuse 与 specular 上：

11-light-casters/point.rkt：距离与衰减，以及乘给谁源码 ↗
          (vec-3 light-dir (normalize (- u-light-pos v-frag-pos)))
          (float distance (length (- u-light-pos v-frag-pos)))
          ;; 衰减：分母里的三项各管一段距离（见页面上那张曲线与参数表）。
          ;; d = 0 时分母退化成 kc，所以 kc 是"贴着灯时的保底"——它不该是 0。
          (float attenuation (/ 1.0 (+ u-kc (* u-kl distance) (* u-kq distance distance))))
          (float ambient 0.1)
          ;; diffuse 和 specular 都是"这盏灯送来的光"，所以两处都乘 attenuation；
          ;; ambient 不乘：环境光是场景里来回弹的那份光，不是这盏灯给的，
          ;; 乘上去会让远处的背光面越来越黑，与事实不符。
          (float diff (* (max (dot norm light-dir) 0.0) attenuation))

环境光为什么不乘衰减：ambient 那块 0.1 本来就不是「这盏灯送来的光」，而是用来代替场景里光线弹来弹去的那份底光的。它乘上衰减，等于宣称「离灯远的地方连反弹回来的光都少了」——真实的房间里，灯照不到的角落也还亮着一点。所以这一项原样保留，只有 diffuse 与 specular 跟着距离缩水。

场景里四个立方体就排在灯的正前方，中心离灯 1.5 / 3 / 5 / 7。跑起来能看到近的那个明显亮、远的那个发暗——把这几行里的 u-kq 改小、或把 u-kc 改成 0，亮度的梯度会跟着变（见「试试看」）。

11.3 聚光：点光加一个锥

点光四面八方一样亮，手电筒、路灯、舞台追光却不是：光被罩住，只朝一个锥里射。聚光在点光上只多一个判据——这个片元在不在锥里。

做法是拿两个方向做点乘：一个是「从灯指向这个片元」，一个是锥轴 u-light-dir。先把方向写成公式：

toFrag = normalize(fragPos - lightPos)　（从灯指向片元）

cosTheta = dot(toFrag, lightDir)

因为两个方向都归一化了，cosTheta 就是夹角的余弦：片元落在锥轴上时是 1，越靠锥的外沿越小。注意这里的方向是「灯 → 片元」，和点光里「片元 → 灯」的 l 正好相反——聚光要判断的是「光射出去的方向」有没有落在锥里。

再拿 cosTheta 和两个门限比：内锥 12.5° 的余弦、外锥 17.5° 的余弦。因为余弦在 0°..180° 上单调递减，内锥角更小、余弦更大，所以 cosOuter < cosInner。落在内锥里 intensity 给 1、落在外锥外给 0、夹在中间的那 5° 用 smoothstep 平滑过渡：

intensity = smoothstep(cosOuter, cosInner, cosTheta)

smoothstep(edge0, edge1, x) 在 x ≤ edge0 时是 0、x ≥ edge1 时是 1，中间用三次曲线平滑过渡。所以 cosTheta 从外锥余弦走到内锥余弦时，intensity 从 0 平滑升到 1——这段过渡就是锥边的「软」：

11-light-casters/spot.rkt：锥的判定与软边源码 ↗
          (float cos-theta (dot (normalize (- v-frag-pos u-light-pos)) u-light-dir))
          (float intensity (smoothstep u-cos-outer u-cos-inner cos-theta))
          ;; 两件事一起打折扣：锥外 intensity 是 0，整盏灯就照不到；
          ;; 锥内还要按距离衰减。ambient 照旧不乘（它不是这盏灯给的光）。
          (float spot (* intensity attenuation))

本课的聚光把手电筒挂在相机上：u-light-pos 就是相机位置，u-light-dir 就是相机朝向，所以这两个 uniform 每帧都在变（相机绕场景慢慢转圈），光锥跟着一起扫过那排立方体。场景换回 06 课那种多立方体世界——十个立方体散布在原点周围，相机转起来时不同的立方体轮流进出光锥。

关键点上传的是余弦不是角度。片元里比的是 dot 出来的 cos-theta，门限要是写成角度，就得每个像素做一次反三角把 cos-theta 掰回角度——白白多算一次 acos。所以 Racket 侧用 (cos (degrees->radians 12.5)) 先算好再上传，片元里只剩一次比较。角度是给人看的，余弦是给 GPU 用的。

11.4 三种光的包含关系

三个文件不是三套互不相干的公式，而是同一套公式逐次「加回一个被丢掉的量」：

  • 方向光 = 点光推到无穷远：位置跑到无穷远，距离也就无穷大，「灯在哪」和「衰减」这两件事同时失去意义，只剩方向。
  • 点光 = 聚光把锥角开到 180°：外锥角开到半空间，所有方向都满足「在锥内」，intensity 恒为 1，锥这一项就退出了公式，剩下的正是点光。
  • 聚光 = 点光 + 锥：位置、方向、衰减一样不少，多的只是那个 intensity。

所以从 directional.rkt 一路读到 spot.rkt，每份文件的片元都只比上一份多出来几行；把三份并排 diff，多出来的那几行正好就是它比上一种光「多知道的那件事」。

;; ============================================================
;; 11 · 光从哪来（二）：点光与衰减
;; 运行：racket 11-light-casters/point.rkt
;; 上一份：11-light-casters/directional.rkt
;; ============================================================
;; 方向光（directional.rkt）只留了方向，因为它假设光源远到光线已经平行。
;; 灯泡不是这样的：它就挂在房间里，光从这一点向四周辐射，越远越弱。
;; 本节把"位置"和"衰减"两件东西加回来：
;;   point   ① 有位置——u-light-pos 回来了，光方向逐片元算
;;           ② 有衰减——能量摊在半径 d 的球面上，球面积随 d² 涨，于是
;;                        attenuation = 1 / (kc + kl·d + kq·d²)
;; 本文件与 directional.rkt 的差别只有三处（其余逐行相同，可以 diff 着读）：
;;   ① uniform：u-light-pos + u-kc / u-kl / u-kq 顶掉 directional 的 u-light-dir
;;   ② 片元多算 distance 与 attenuation 两行
;;   ③ diffuse 与 specular 各乘一次 attenuation（ambient 不乘，见片元里的注释）
;; 场景也换了：四个立方体从"离相机 0/2/4/6"改成"离灯 1.5/3/5/7"——
;; 同样的四个立方体，这次会因为距离亮成四个档次。

(glsl-shader vert-src
  (version 330 core)
        (layout (location 0) in vec-3 pos)
        (layout (location 1) in vec-3 normal)
        (uniform mat-4 u-model)
        (uniform mat-4 u-view)
        (uniform mat-4 u-proj)
        (uniform mat-3 u-normal-matrix)
        (out vec-3 v-normal)
        (out vec-3 v-frag-pos)
        (define (main) void
          (set! v-normal (* u-normal-matrix normal))
          (set! v-frag-pos (vec-3 (* u-model (vec-4 pos 1.0))))
          (set! gl-position (* u-proj (* u-view (* u-model (vec-4 pos 1.0)))))))

;; 物体的片元：在 directional 的三项上加了 distance 与 attenuation。
;;
;; light-dir 这次要逐片元算——"从这一点指向灯"的方向，每个像素都不一样，
;; 这正是方向光省掉的那件事（它整帧共用一个方向）。
(glsl-shader frag-src
  (version 330 core)
        (in vec-3 v-normal)
        (in vec-3 v-frag-pos)
        (uniform vec-3 u-light-pos)               ; 灯在世界里的位置
        (uniform float u-kc)                    ; 衰减的常数项
        (uniform float u-kl)                    ; 衰减的线性项
        (uniform float u-kq)                    ; 衰减的二次项
        (uniform vec-3 u-light-color)
        (uniform vec-3 u-view-pos)
        (uniform vec-3 u-object-color)
        (out vec-4 frag-color)
        (define (main) void
          (vec-3 norm (normalize v-normal))
          (vec-3 light-dir (normalize (- u-light-pos v-frag-pos)))
          (float distance (length (- u-light-pos v-frag-pos)))
          ;; 衰减：分母里的三项各管一段距离（见页面上那张曲线与参数表）。
          ;; d = 0 时分母退化成 kc，所以 kc 是"贴着灯时的保底"——它不该是 0。
          (float attenuation (/ 1.0 (+ u-kc (* u-kl distance) (* u-kq distance distance))))
          (float ambient 0.1)
          ;; diffuse 和 specular 都是"这盏灯送来的光"，所以两处都乘 attenuation；
          ;; ambient 不乘：环境光是场景里来回弹的那份光，不是这盏灯给的，
          ;; 乘上去会让远处的背光面越来越黑，与事实不符。
          (float diff (* (max (dot norm light-dir) 0.0) attenuation))
          (vec-3 reflect-dir (reflect (- light-dir) norm))
          (vec-3 view-dir (normalize (- u-view-pos v-frag-pos)))
          (float spec (* (* (pow (max (dot view-dir reflect-dir) 0.0) 32.0) 0.5) attenuation))
          (set! frag-color (vec-4 (* (+ ambient diff spec) u-light-color u-object-color) 1.0))))

;;   · light-pos 的 z 从 2.0 改成 0.0：灯挪到第二个立方体旁边，近的两个更亮、
;;     远的两个更暗——把"距离"这个变量整体挪一挪，梯度跟着挪。
;; ============================================================

;; ============================================================
;; 11 · 光从哪来（三）：聚光
;; 运行：racket 11-light-casters/spot.rkt
;; 上一份：11-light-casters/point.rkt
;; ============================================================
;; 点光向四周辐射，四面八方一样亮。手电筒、路灯、舞台追光不是这样：光被罩住，
;; 只朝一个锥里射。本节在点光上加一个锥：
;;   spot   ① 有位置、有衰减（照抄 point）——手电筒还是"一盏灯"
;;          ② 多一个方向：光锥的轴
;;          ③ 多一个锥角：内外两个角，边界用 smoothstep 做软过渡
;; 本文件与 point.rkt 的差别只有三处（其余逐行相同，可以 diff 着读）：
;;   ① uniform：多出 u-light-dir / u-cos-inner / u-cos-outer
;;   ② 片元多算 cos-theta 与 intensity 两行
;;   ③ diffuse / specular 乘的是 intensity × attenuation，而不是单独一个 attenuation
;;
;; 相机这次在动：手电筒挂在相机上（位置 = 相机位置、方向 = 相机朝向），
;; 相机绕着场景慢慢转圈，光锥跟着扫过一排立方体。为此本课第一次在 11 课里用了 timer。

;; ------------------------------------------------------------
;; 顶点着色器与 point.rkt 逐行相同。
(glsl-shader vert-src
  (version 330 core)
        (layout (location 0) in vec-3 pos)
        (layout (location 1) in vec-3 normal)
        (uniform mat-4 u-model)
        (uniform mat-4 u-view)
        (uniform mat-4 u-proj)
        (uniform mat-3 u-normal-matrix)
        (out vec-3 v-normal)
        (out vec-3 v-frag-pos)
        (define (main) void
          (set! v-normal (* u-normal-matrix normal))
          (set! v-frag-pos (vec-3 (* u-model (vec-4 pos 1.0))))
          (set! gl-position (* u-proj (* u-view (* u-model (vec-4 pos 1.0)))))))

;; 物体的片元：在 point 的"位置 + 衰减"上再加一段锥的判定。
;;
;; cos-theta 是"从灯指向这一点的方向"与"锥轴"的夹角余弦：锥轴上为 1，
;; 越往锥的外沿越小。拿它和两个门限比，就知道这个片元在锥里、锥外、还是边上：
;;   cos-theta ≥ u-cos-inner   在锥心里，intensity = 1
;;   cos-theta ≤ u-cos-outer   在锥外，intensity = 0
;;   两者之间              边上，smoothstep 给一段平滑过渡（不是硬切）
;; 传进来的门限是余弦而不是角度：因为这里比的就是 cos-theta，两边都化成余弦就不用
;; 在片元里做反三角（见页面上 11.3 的 note.key）。
(glsl-shader frag-src
  (version 330 core)
        (in vec-3 v-normal)
        (in vec-3 v-frag-pos)
        (uniform vec-3 u-light-pos)               ; 灯的（也就是相机的）位置
        (uniform vec-3 u-light-dir)               ; 锥轴：相机朝向
        (uniform float u-cos-inner)              ; 内锥角的余弦
        (uniform float u-cos-outer)              ; 外锥角的余弦
        (uniform float u-kc)
        (uniform float u-kl)
        (uniform float u-kq)
        (uniform vec-3 u-light-color)
        (uniform vec-3 u-view-pos)
        (uniform vec-3 u-object-color)
        (out vec-4 frag-color)
        (define (main) void
          (vec-3 norm (normalize v-normal))
          (vec-3 light-dir (normalize (- u-light-pos v-frag-pos)))
          (float distance (length (- u-light-pos v-frag-pos)))
          (float attenuation (/ 1.0 (+ u-kc (* u-kl distance) (* u-kq distance distance))))
          (float cos-theta (dot (normalize (- v-frag-pos u-light-pos)) u-light-dir))
          (float intensity (smoothstep u-cos-outer u-cos-inner cos-theta))
          ;; 两件事一起打折扣：锥外 intensity 是 0，整盏灯就照不到；
          ;; 锥内还要按距离衰减。ambient 照旧不乘（它不是这盏灯给的光）。
          (float spot (* intensity attenuation))
          (float ambient 0.1)
          (float diff (* (max (dot norm light-dir) 0.0) spot))
          (vec-3 reflect-dir (reflect (- light-dir) norm))
          (vec-3 view-dir (normalize (- u-view-pos v-frag-pos)))
          (float spec (* (* (pow (max (dot view-dir reflect-dir) 0.0) 32.0) 0.5) spot))
          (set! frag-color (vec-4 (* (+ ambient diff spec) u-light-color u-object-color) 1.0))))

(define (draw)
  (define t (/ (current-inexact-monotonic-milliseconds) 1000.0))

  (gl-clear-color 0.10 0.12 0.20 1.0)
  (gl-clear (bitwise-ior gl-color-buffer-bit gl-depth-buffer-bit))

  (define eye (vec-3 (* orbit-radius (cos (* t orbit-speed)))
                    orbit-height
                    (* orbit-radius (sin (* t orbit-speed)))))
  (define view (m-look-at eye scene-center (vec-3 0.0 1.0 0.0)))
  ;; 视场这里开大到 70°（其余各课都是 45°）：光锥全角只有 35°，而手电筒又挂在相机上，

  (define proj (m-perspective (degrees->radians 70.0) aspect 0.1 100.0))

  ;; 相机每帧都在动，所以 u-light-dir 也得每帧重算——不像方向光的 u-light-dir 是个常量，
  ;; 也不像 point 的 u-light-pos 一动不动。相机转，光锥跟着一起转，扫过这排立方体。

  (uniform-set! u-proj-loc 'mat-4 proj)

  (uniform-set! u-kl-loc 'float k-linear)
  (uniform-set! u-kq-loc 'float k-quadratic)

试试看

  1. 点光里把 k-quadratic 从 0.032 改成 0.007（片元里就是 u-kq）：远段掉得慢多了，最远那个立方体明显抬亮——对照图 11-1 那条曲线，等于把右半段的陡坡压平。
  2. 点光里把 k-constant 从 1.0 改成 0.0：分母失去保底，d 很小时 attenuation 冲过 1，最近的立方体直接爆亮成一片白。这就是 kc 非要留在 1.0 的原因。
  3. 聚光里把 smoothstep 换成手写的硬阶跃，锥边立刻从软变硬：
    (float intensity (if (> cos-theta u-cos-inner) 1.0 0.0))
    （片元语句里的 if 不可用，那位置留给三元表达式；(if 条件 甲 乙) 在表达式位才写成 cond ? 甲 : 乙，正好够这一行用。）
  4. 聚光里把锥角改小：inner-deg / outer-deg 从 12.5 / 17.5 改成 5.0 / 8.0。光斑收窄成一小块，画面上只剩正中那个立方体亮着；反过来改成 60.0 / 90.0，画面就慢慢变成点光那节的样子——锥开到 180° 就是点光（11.4）。
  5. 方向光里把 light-dir 从 (vec-3 -0.2 -1.0 -0.3) 改成 (vec-3 0.0 -1.0 0.0)（正午的太阳，光垂直往下）：四个立方体只剩顶面亮，前面和侧面一起暗下去，只剩一点环境光。同一个面亮不亮，全看它朝哪——这就是方向光里唯一的变量。

GPU 资源本节创建的 program / VAO / VBO（以及纹理）都在文件末尾的 shutdown 里用 program-delete / vertex-array-delete / buffer-delete 显式删除，由 #:on-close shutdown 在关窗时触发。为什么这些句柄 GC 管不了、为什么必须手动删，见 02 · 2.9。

小结

光源 有位置？ 有方向？ 有衰减？ 有锥？ 公式里多出来的那一项
方向光 directional 否（在无穷远） 是（常量） 否 否 没有；light-dir = normalize(-u-light-dir)，距离不进公式
点光 point 是 是（逐片元算） 是 否 attenuation = 1 / (kc + kl·d + kq·d²)，乘在 diffuse 与 specular 上
聚光 spot 是 是（锥轴） 是 是 intensity = smoothstep(cosOuter, cosInner, cosθ)，与 attenuation 一起乘
