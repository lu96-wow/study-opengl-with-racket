纹理

本节目标：给矩形贴上一张代码生成的棋盘图，顺路把纹理的四件事讲完——像素怎么上传到显存、UV 怎么决定每个角取图的哪里、UV 超出 0..1 时怎么办、纹理被放大和缩小时怎么取像素。最后再叠上第二张图，把纹理单元和 mix 用起来。跑起来应该看到矩形上是 8×8 的棋盘，上面还盖着一层中心亮、边缘暗的渐变。

$ racket 04-textures/textures.rkt

计算位置棋盘/渐变像素在 CPU 生成，再上传成纹理；UV 插值、wrap、filter、mipmap 采样都在 GPU 的片元着色器和纹理单元里。CPU 可以逐像素采样，但成本随像素数增长。数据流：CPU 像素 → texture → 片元采样 → 屏幕。

4.1 纹理对象与上传

纹理在 OpenGL 里就是显存中的一块「图」，对外用一个 id 指代。上传一张图三步：texture-new 生成 id → gl-bind-texture gl-texture-2d 把它设为「当前纹理」→ 再用 gl-tex-image-2d 把像素拷进去。和缓冲一样，这些 gl-* 调用作用在「当前绑定」的对象上。

04-textures/textures.rkt：创建纹理对象并设为当前源码 ↗
  ;; 纹理对象：显存里的一块"图"。texture-new 生成编号，gl-bind-texture 设为当前。
  (set! texture (texture-new))
  (gl-bind-texture gl-texture-2d texture)

接下来设环绕和过滤参数（4.3、4.4 讲），然后上传像素。本课上传那一步是：

04-textures/textures.rkt：上传像素源码 ↗
  ;; 上传像素：gl-tex-image-2d(目标, mip 层, 内部格式, 宽, 高, 边框, 输入格式, 输入类型, 数据)
  ;; 这里 RGBA8：内部格式/输入格式都是 gl-rgba，类型 gl-unsigned-byte。
  (define checker (make-checker-texture tex-size tex-cell))
  (gl-tex-image-2d gl-texture-2d 0 gl-rgba tex-size tex-size 0
                   gl-rgba gl-unsigned-byte checker)

gl-tex-image-2d 参数最多，九个逐个看：

参数 本课的值 含义
目标 gl-texture-2d 这是 2D 纹理；OpenGL 还有 1D、3D、立方体贴图等其他目标
mip 层 0 传的是第几层 mipmap，0 是原图那一层
内部格式 gl-rgba GPU 端按什么格式存这张图：RGBA 四个通道各 8 位
宽 tex-size 纹理的宽，本课 64 像素
高 tex-size 纹理的高，本课 64 像素
边框 0 老 API 的遗留参数，必须写 0
输入格式 gl-rgba 我们递过去的数据是每像素 RGBA
输入类型 gl-unsigned-byte 每个分量是 0-255 的字节
数据 checker 那条连续的字节流，长度 = 宽 × 高 × 4

本课是 RGBA8：内部格式和输入格式都写 gl-rgba、输入类型 gl-unsigned-byte，数据是每像素 4 字节的 u8-array（每个分量 0-255，第四个是 alpha）。

4.2 UV 坐标

图上传好了，还得告诉 GPU「这个角取图的哪里」。这个信息同样放在顶点上：本课顶点属性 1 是 a-uv，一个 vec-2。

UV 是什么：u / v 是纹理空间的二维坐标，不是屏幕坐标，也不是像素下标。u 横向、v 纵向，通常归一化到 0..1：(0,0) 是图的一角，(1,1) 是对角。

概念例子说明
UV 坐标(0.0, 0.0)、(1.0, 1.0)纹理空间的比例坐标，与纹理分辨率无关
像素坐标(0, 0) … (W-1, H-1)纹理像素表里的实际下标
换算u*W、v*HUV 落在哪个像素附近；具体取整/插值由 filter 决定

每个顶点带一个 UV；三角形/四边形内部的 UV 由 GPU 插值，片元着色器再用插值后的 UV 采样：

texel = texture(u-tex, v-uv)

UV 不要求限制在 0..1：大于 1 或小于 0 时由 wrap 模式决定平铺、镜像还是拉伸。UV 也可以缩放、偏移、旋转、翻转，所以几何形状和纹理形状不需要一致。4.9 会把同一张矩形纹理贴到三角形，就是为了看清这一点。

方向约定要小心：传统 OpenGL 纹理坐标 v=0 在底部，但最终取决于你上传像素时的行序。本课自己生成的棋盘上下对称，看不出差别；换成真实图片时，要么上传前翻转行序，要么在 shader 里用 1.0 - v。

（4.8 会再加一个采样器 u-overlay，采样这一步的写法不变。）

04-textures/textures.rkt：UV 属性与 texture 采样源码 ↗
(define vert-src
  (glsl (version 330 core)
        (layout (location 0) in vec-2 a-pos)     ; 属性 0：位置
        (layout (location 1) in vec-2 a-uv)      ; 属性 1：UV 坐标
        (out vec-2 v-uv)
        (define (main) void
          (set! gl-position (vec-4 a-pos 0.0 1.0))
          (set! v-uv a-uv))))

(define frag-src
  (glsl (version 330 core)
        (in vec-2 v-uv)
        (uniform sampler-2d u-tex)               ; 采样器：指向某张纹理
        (uniform sampler-2d u-overlay)           ; 第二个采样器：指向叠在上面的那张
        (out vec-4 frag-color)
        (define (main) void
          ;; texture(采样器, UV) → 这张图在 UV 处的颜色
          ;; mix(a, b, t) = a*(1-t) + b*t：GLSL 内建的逐分量线性插值。
          ;; t=0 全取 a、t=1 全取 b；0.35 让棋盘占大头、径向渐变盖在上面。
          (set! frag-color (mix (texture u-tex v-uv) (texture u-overlay v-uv) 0.35)))))

顶点数据里，每个角的位置后面就跟一对 UV：

04-textures/textures.rkt：位置与 UV 交错源码 ↗
;;    x  y  u  v | x  y  u  v | …
;; UV 约定：(0,0) 是图的一角，(1,1) 是对角。给矩形四个角配上对应 UV。
(define vertex-data
  (concat-vecs (vec-2  0.5  0.5) (vec-2 1.0 1.0)     ; 右上
               (vec-2  0.5 -0.5) (vec-2 1.0 0.0)     ; 右下
               (vec-2 -0.5 -0.5) (vec-2 0.0 0.0)     ; 左下
               (vec-2 -0.5  0.5) (vec-2 0.0 1.0)))   ; 左上

4.3 环绕 wrap

采样时 UV 落在 0..1 之外怎么办？这由环绕方式决定，S、T 两个方向各设一次：

常量 UV 超出 0..1 时的行为
gl-repeat 平铺重复：UV 的小数部分接着用，整张图一格一格铺满
gl-clamp-to-edge 拉边缘像素：超出部分的颜色就是边界那一行 / 一列的像素
gl-mirrored-repeat 镜像重复：像 repeat，但每铺一张就翻一次，接缝对得上
04-textures/textures.rkt：环绕方式源码 ↗
  ;; 环绕方式：UV 超出 0..1 时，REPEAT = 平铺重复（另有 CLAMP_TO_EDGE 等）。
  (gl-tex-parameter-i gl-texture-2d gl-texture-wrap-s gl-repeat)
  (gl-tex-parameter-i gl-texture-2d gl-texture-wrap-t gl-repeat)

4.4 过滤 filter

纹理像素和屏幕像素不是一一对应的，取色时得决定怎么算：纹理被放大时用 mag-filter，被缩小时用 min-filter，两个分开设。

gl-nearest 取离采样点最近的那一个像素——近看能看出方块；gl-linear 取周围 4 个像素的加权平均——放大后是平滑过渡。本课放大用 LINEAR：

04-textures/textures.rkt：过滤方式源码 ↗
  ;; 过滤：放大用 LINEAR（平滑）；缩小用 LINEAR_MIPMAP_LINEAR（在 mipmap 层之间插值）。
  (gl-tex-parameter-i gl-texture-2d gl-texture-min-filter gl-linear-mipmap-linear)
  (gl-tex-parameter-i gl-texture-2d gl-texture-mag-filter gl-linear)

4.5 mipmap

反过来，纹理在屏幕上占得很小时，一个屏幕像素会盖住一大片纹理，只取一个样点就会闪烁、出摩尔纹。mipmap 是预先算好的一串副本：每层边长减半，层数一直往下直到 1×1。

本课缩小用的过滤写成 gl-linear-mipmap-linear：不但在同一层内插值，还在相邻两层之间插值。

坑过滤方式的名字里带 mipmap，就必须调一次 gl-generate-mipmap 把这一串副本算出来。少了这一步，纹理是不完整的，采样结果是黑的——这是纹理里最常见的坑。

04-textures/textures.rkt：生成 mipmap源码 ↗
  ;; ★用了 mipmap 过滤就必须生成 mipmap，否则纹理不完整、采样结果是黑的（常见坑）。
  (gl-generate-mipmap gl-texture-2d)

4.6 纹理单元与 sampler-2d

片元着色器里的 uniform sampler-2d u-tex 看着像「一张纹理」，其实编译到 GPU 上它就是一个整数，含义是「用几号纹理单元」。纹理单元是采样器的插槽：gl-active-texture 选槽 → gl-bind-texture 把纹理绑到槽上 → (uniform-set! loc 'sampler-2d 0) 把槽号告诉采样器。只有一个纹理时用 0 号槽——4.8 会真的用上 1 号槽。

04-textures/textures.rkt：把纹理告诉采样器源码 ↗
  ;; 采样器 u-tex 是一个整数，含义是"用几号纹理单元"。
  ;; 纹理单元是采样器的"插槽"：先用 gl-active-texture 选槽，再把纹理绑到槽上。
  ;; 只有一个纹理时用 0 号槽。
  (program-use program)                       ; uniform 作用在"当前程序"上
  (uniform-set! (uniform-location program "u_tex") 'sampler-2d 0)
  (gl-active-texture gl-texture0)
  (gl-bind-texture gl-texture-2d texture)

关键点uniform-set! 配 'sampler-2d 上传的是槽号，不是纹理 id；槽号是「几号插槽」，纹理 id 是「哪张图」，两者不要混。和其他 uniform 一样，上传要在 program-use 之后。

4.7 用代码生成纹理，不依赖图片文件

本课的棋盘图是算出来的：一个 size × size 的 u8-array，每像素 4 个字节，按 cell × cell 的格子交替填两种颜色。这里用 make-u8-array / u8-array-set!；裸写法是 ffi 的 (make-u8vector n 255) / (u8vector-set! px i v)（u8vector 就是 bytes），u8-array 家族只是命名版并做 0..255 检查。

04-textures/textures.rkt：生成棋盘像素源码 ↗
(define (make-checker-texture size cell)
  (define px (make-u8-array (* size size 4) 255))
  (for* ([y (in-range size)] [x (in-range size)])
    (define on? (even? (+ (quotient x cell) (quotient y cell))))
    (define i (* (+ (* y size) x) 4))
    (define r (if on? 230 40))
    (define g (if on? 140 70))
    (define b (if on? 60 130))
    (u8-array-set! px i r)
    (u8-array-set! px (+ i 1) g)
    (u8-array-set! px (+ i 2) b)
    (u8-array-set! px (+ i 3) 255))          ; alpha 不透明
  px)

选棋盘是有意的：纹理的四个话题在这个图案上都看得见——贴对了是一格一格的方块，UV 取到 2 就数出更多格，mag-filter 换成 nearest 方块边就变硬，删掉 gl-generate-mipmap 直接变黑。

换成真实图片也不难：用 racket/draw 的 read-bitmap 读文件，再用 get-argb-pixels 取出 RGBA 字节，同样喂给 gl-tex-image-2d 就行，这里不展开。

坑换成真图之前，先记住两个 (0,0) 不是同一个角：位图自己的 (0,0) 在左上角，OpenGL 纹理的 (0,0) 在左下角。read-bitmap 读出来的行序直接喂 gl-tex-image-2d，图会上下颠倒。两种解法：上传前把行序倒过来（Racket 侧一行 for/vector 反向索引即可），或者不碰数据、在片元里翻一下 v：(texture u-tex (vec-2 (vx v-uv) (- 1.0 (vy v-uv))))。本课自己生成的棋盘上下对称，撞不上这个坑；换成真实图片才会。

4.8 两张贴图叠起来：第二个纹理单元与 mix

一个采样器够用，是因为前面只有一张图。要再叠一张，就得要第二个插槽——也就是 4.6 说的纹理单元：0 号槽给 u-tex，1 号槽给新的 u-overlay。绑定步骤和第一张一模一样，只是换了槽号、换了图：

槽号常量是连续的：gl-texture0 就是 GL_TEXTURE0，第 i 号槽写 (+ gl-texture0 i)——learnopengl 的 C++ 里同样是 GL_TEXTURE0 + i。racket-shader 收录了 gl-texture0–gl-texture3，本课直接用 gl-texture1；多于一张图要循环绑槽时写 (+ gl-texture0 i) 同样合法。

04-textures/textures.rkt：第二张贴图绑到 1 号纹理单元源码 ↗
  ;; 第二张贴图要第二个插槽：0 号槽给 u-tex、1 号槽给 u-overlay，采样器靠 uniform 整数认槽。
  ;; 步骤和上面一样：选槽 → 绑纹理 → 设参数 → 传像素 → 生成 mipmap → 报槽号。
  (set! overlay (texture-new))
  ;; 1 号槽就是 gl-texture1；槽号常量连续（GL_TEXTURE0 + i 即第 i 号槽），
  ;; 本库收录到 gl-texture3，循环里仍可写 (+ gl-texture0 i)。
  (gl-active-texture gl-texture1)
  (gl-bind-texture gl-texture-2d overlay)
  (gl-tex-parameter-i gl-texture-2d gl-texture-wrap-s gl-repeat)
  (gl-tex-parameter-i gl-texture-2d gl-texture-wrap-t gl-repeat)
  (gl-tex-parameter-i gl-texture-2d gl-texture-min-filter gl-linear-mipmap-linear)
  (gl-tex-parameter-i gl-texture-2d gl-texture-mag-filter gl-linear)
  (gl-tex-image-2d gl-texture-2d 0 gl-rgba tex-size tex-size 0
                   gl-rgba gl-unsigned-byte (make-radial-texture tex-size))
  (gl-generate-mipmap gl-texture-2d)
  (uniform-set! (uniform-location program "u_overlay") 'sampler-2d 1)

第二张图照样是算出来的（生成函数在下面的「完整代码」里）：每像素按到中心的距离取灰度，中心亮、边缘暗。选它是故意的——棋盘是硬的边界，径向是软的明暗，叠起来两种特征都还看得见。

槽都就位了，片元里再各采一次，把两个结果合起来。合用 GLSL 内建的 mix：

04-textures/textures.rkt：mix 把两个采样结果合起来源码 ↗
(define frag-src
  (glsl (version 330 core)
        (in vec-2 v-uv)
        (uniform sampler-2d u-tex)               ; 采样器：指向某张纹理
        (uniform sampler-2d u-overlay)           ; 第二个采样器：指向叠在上面的那张
        (out vec-4 frag-color)
        (define (main) void
          ;; texture(采样器, UV) → 这张图在 UV 处的颜色
          ;; mix(a, b, t) = a*(1-t) + b*t：GLSL 内建的逐分量线性插值。
          ;; t=0 全取 a、t=1 全取 b；0.35 让棋盘占大头、径向渐变盖在上面。
          (set! frag-color (mix (texture u-tex v-uv) (texture u-overlay v-uv) 0.35)))))

mix(a, b, t) 就是逐分量算 a*(1-t) + b*t：t = 0.35 表示棋盘占 0.65、径向渐变占 0.35。所以画面上棋盘还在，只是整体被径向的明暗压了一层——中心被提亮，四角被压暗。

关键点mix 的第三个参数不一定是常数，也可以是另一张纹理的某个分量：比如拿 overlay 的 r 当掩码，亮的地方取一张图、暗的地方取另一张，就是「按图抠像」——它也是后面光照章把光照色和物体色混起来的同一个函数。

4.9 补充：同一张矩形纹理贴到三角形

先纠正一个常见误解：纹理不是“用矩形算”的。纹理在显存里是一张 width × height 的像素表，但“贴到哪”完全由 UV 决定。几何可以是三角形、四边形、任意 mesh，不需要和纹理形状一致。

东西形状谁决定
纹理存储矩形像素表gl-tex-image-2d 的 width / height
几何三角形 / 四边形 / mesh顶点位置
映射表面上的 UV每个顶点一个 UV；三角形内部由 GPU 插值

04-textures/triangle-texture.rkt 用同一张棋盘纹理画一个三角形。三个顶点的 UV 是：

(vec-2 -0.6 -0.6) (vec-2 0.0 0.0)   ; 左下
(vec-2  0.6 -0.6) (vec-2 1.0 0.0)   ; 右下
(vec-2  0.0  0.6) (vec-2 0.5 1.0)   ; 上中

所以三角形显示的是棋盘下半部分的一个三角形裁片：纹理仍然是完整矩形，只是片元只采样到三角形覆盖的那一块 UV 区域。

如果想用三角形显示完整矩形，是做不到“不裁不拉伸”的：矩形有四个角，三角形只有三个顶点，最多只能覆盖三个角。你可以：

  • 换成四边形（两个三角形），四个角各给一个 UV；
  • 或者接受拉伸/裁切，把三个 UV 映射到矩形的一部分。

关键点上传纹理和几何形状是两件事：gl-tex-image-2d 只关心像素表；texture(u-tex, v-uv) 在每个片元上按插值后的 UV 采样。三角形、四边形、曲面都可以用同一张纹理，区别只在 UV 怎么给。

完整代码

04-textures/textures.rkt，本课全部代码（直接 racket 跑）：

04-textures/textures.rkt源码 ↗
#lang glsl-opengl
;; ============================================================
;; 04 · 纹理
;; 运行：racket 04-textures/textures.rkt
;; 上一课：03-shaders/shaders.rkt
;; ============================================================
;; 目标：把一个矩形"贴"上一张图。纹理要讲的四件事：
;;   ① 纹理对象：把像素数据上传到显存
;;   ② UV 坐标：顶点上告诉 GPU "这个角取图的哪里"
;;   ③ 环绕（wrap）：UV 超出 0..1 时怎么办
;;   ④ 过滤 + mipmap：纹理被放大/缩小时怎么取像素
;; 这里用代码生成两张图（棋盘 + 径向渐变），不用外部图片文件。

(require racket/class
         "../lib/window.rkt")

;; ------------------------------------------------------------
;; 一、生成纹理像素
;; ------------------------------------------------------------
;; OpenGL 要的是"一条连续的 RGBA 字节流"（每像素 4 个字节，0-255）。
;; 这里画一张 size×size 的棋盘：每个 cell×cell 的方块在两种颜色之间交替。
(define tex-size 64)
(define tex-cell 8)

(define (make-checker-texture size cell)
  (define px (make-u8-array (* size size 4) 255))
  (for* ([y (in-range size)] [x (in-range size)])
    (define on? (even? (+ (quotient x cell) (quotient y cell))))
    (define i (* (+ (* y size) x) 4))
    (define r (if on? 230 40))
    (define g (if on? 140 70))
    (define b (if on? 60 130))
    (u8-array-set! px i r)
    (u8-array-set! px (+ i 1) g)
    (u8-array-set! px (+ i 2) b)
    (u8-array-set! px (+ i 3) 255))          ; alpha 不透明
  px)

;; 第二张图是径向渐变：每像素按到中心的距离取灰度，中心亮、边缘暗。
;; 选它是为了和棋盘的"硬边"形成对比——两个采样结果 mix 之后两种特征都还看得见。
(define (make-radial-texture size)
  (define center (/ (- size 1) 2.0))                 ; 图中心的像素坐标
  (define span (sqrt (* 2.0 center center)))         ; 中心到角的距离，用来归一化
  (define px (make-u8-array (* size size 4) 255))
  (for* ([y (in-range size)] [x (in-range size)])
    (define dx (- x center))
    (define dy (- y center))
    (define d (sqrt (+ (* dx dx) (* dy dy))))       ; 到中心的距离
    (define v (inexact->exact (round (* 255.0 (- 1.0 (/ d span))))))
    (define i (* (+ (* y size) x) 4))
    (u8-array-set! px i v)
    (u8-array-set! px (+ i 1) v)
    (u8-array-set! px (+ i 2) v)
    (u8-array-set! px (+ i 3) 255))          ; alpha 不透明
  px)

;; ------------------------------------------------------------
;; 二、着色器：用 UV 采样纹理
;; ------------------------------------------------------------
;; 顶点多了一个属性 a-uv：每个顶点对应图片上的哪个位置（0..1）。
;; 片元着色器用 sampler-2d（采样器）按 UV 去"取颜色"。
;; v-uv 和颜色一样会被插值，所以矩形内部每个像素都拿到自己的 UV。
(define vert-src
  (glsl (version 330 core)
        (layout (location 0) in vec-2 a-pos)     ; 属性 0：位置
        (layout (location 1) in vec-2 a-uv)      ; 属性 1：UV 坐标
        (out vec-2 v-uv)
        (define (main) void
          (set! gl-position (vec-4 a-pos 0.0 1.0))
          (set! v-uv a-uv))))

(define frag-src
  (glsl (version 330 core)
        (in vec-2 v-uv)
        (uniform sampler-2d u-tex)               ; 采样器：指向某张纹理
        (uniform sampler-2d u-overlay)           ; 第二个采样器：指向叠在上面的那张
        (out vec-4 frag-color)
        (define (main) void
          ;; texture(采样器, UV) → 这张图在 UV 处的颜色
          ;; mix(a, b, t) = a*(1-t) + b*t：GLSL 内建的逐分量线性插值。
          ;; t=0 全取 a、t=1 全取 b；0.35 让棋盘占大头、径向渐变盖在上面。
          (set! frag-color (mix (texture u-tex v-uv) (texture u-overlay v-uv) 0.35)))))

;; ------------------------------------------------------------
;; 三、顶点数据：位置(vec-2) + UV(vec-2) 交错，共 4 个 float = 16 字节
;; ------------------------------------------------------------
;;    x  y  u  v | x  y  u  v | …
;; UV 约定：(0,0) 是图的一角，(1,1) 是对角。给矩形四个角配上对应 UV。
(define vertex-data
  (concat-vecs (vec-2  0.5  0.5) (vec-2 1.0 1.0)     ; 右上
               (vec-2  0.5 -0.5) (vec-2 1.0 0.0)     ; 右下
               (vec-2 -0.5 -0.5) (vec-2 0.0 0.0)     ; 左下
               (vec-2 -0.5  0.5) (vec-2 0.0 1.0)))   ; 左上

(define indices (u16-array 0 1 2   0 2 3))          ; 两个三角形拼成矩形

(define program #f)
(define vao #f)
(define texture #f)
(define overlay #f)

(define (init)
  (set! program (build-program (gl-vertex-shader vert-src)
                               (gl-fragment-shader frag-src)))

  ;; ---- 3.1 创建并上传纹理 ----
  ;; 纹理对象：显存里的一块"图"。texture-new 生成编号，gl-bind-texture 设为当前。
  (set! texture (texture-new))
  (gl-bind-texture gl-texture-2d texture)

  ;; 环绕方式：UV 超出 0..1 时，REPEAT = 平铺重复（另有 CLAMP_TO_EDGE 等）。
  (gl-tex-parameter-i gl-texture-2d gl-texture-wrap-s gl-repeat)
  (gl-tex-parameter-i gl-texture-2d gl-texture-wrap-t gl-repeat)
  ;; 过滤：放大用 LINEAR（平滑）；缩小用 LINEAR_MIPMAP_LINEAR（在 mipmap 层之间插值）。
  (gl-tex-parameter-i gl-texture-2d gl-texture-min-filter gl-linear-mipmap-linear)
  (gl-tex-parameter-i gl-texture-2d gl-texture-mag-filter gl-linear)

  ;; 上传像素：gl-tex-image-2d(目标, mip 层, 内部格式, 宽, 高, 边框, 输入格式, 输入类型, 数据)
  ;; 这里 RGBA8：内部格式/输入格式都是 gl-rgba，类型 gl-unsigned-byte。
  (define checker (make-checker-texture tex-size tex-cell))
  (gl-tex-image-2d gl-texture-2d 0 gl-rgba tex-size tex-size 0
                   gl-rgba gl-unsigned-byte checker)

  ;; ★用了 mipmap 过滤就必须生成 mipmap，否则纹理不完整、采样结果是黑的（常见坑）。
  (gl-generate-mipmap gl-texture-2d)

  ;; ---- 3.2 把纹理告诉采样器 ----
  ;; 采样器 u-tex 是一个整数，含义是"用几号纹理单元"。
  ;; 纹理单元是采样器的"插槽"：先用 gl-active-texture 选槽，再把纹理绑到槽上。
  ;; 只有一个纹理时用 0 号槽。
  (program-use program)                       ; uniform 作用在"当前程序"上
  (uniform-set! (uniform-location program "u_tex") 'sampler-2d 0)
  (gl-active-texture gl-texture0)
  (gl-bind-texture gl-texture-2d texture)

  ;; 第二张贴图要第二个插槽：0 号槽给 u-tex、1 号槽给 u-overlay，采样器靠 uniform 整数认槽。
  ;; 步骤和上面一样：选槽 → 绑纹理 → 设参数 → 传像素 → 生成 mipmap → 报槽号。
  (set! overlay (texture-new))
  ;; 1 号槽就是 gl-texture1；槽号常量连续（GL_TEXTURE0 + i 即第 i 号槽），
  ;; 本库收录到 gl-texture3，循环里仍可写 (+ gl-texture0 i)。
  (gl-active-texture gl-texture1)
  (gl-bind-texture gl-texture-2d overlay)
  (gl-tex-parameter-i gl-texture-2d gl-texture-wrap-s gl-repeat)
  (gl-tex-parameter-i gl-texture-2d gl-texture-wrap-t gl-repeat)
  (gl-tex-parameter-i gl-texture-2d gl-texture-min-filter gl-linear-mipmap-linear)
  (gl-tex-parameter-i gl-texture-2d gl-texture-mag-filter gl-linear)
  (gl-tex-image-2d gl-texture-2d 0 gl-rgba tex-size tex-size 0
                   gl-rgba gl-unsigned-byte (make-radial-texture tex-size))
  (gl-generate-mipmap gl-texture-2d)
  (uniform-set! (uniform-location program "u_overlay") 'sampler-2d 1)

  ;; ---- 3.3 VAO / VBO / EBO ----
  (set! vao (vertex-array-new))
  (gl-bind-vertex-array vao)

  (define vbo (buffer-new))
  (gl-bind-buffer gl-array-buffer vbo)
  (buffer-upload gl-array-buffer vertex-data gl-static-draw)
  ;; 步长和偏移都从布局算出来，不写字面量。
  (define stride (shader-stride-bytes 'vec-2 'vec-2))   ; 2 + 2 = 4 个 float = 16 字节
  (define uv-offset (shader-byte-size 'vec-2))         ; 跳过位置那 2 个 float = 8 字节
  (gl-vertex-attrib-pointer 0 2 gl-float #f stride 0)
  (gl-enable-vertex-attrib-array 0)
  (gl-vertex-attrib-pointer 1 2 gl-float #f stride uv-offset)
  (gl-enable-vertex-attrib-array 1)

  (define ebo (buffer-new))
  (gl-bind-buffer gl-element-array-buffer ebo)
  (buffer-upload gl-element-array-buffer indices gl-static-draw)

  (gl-bind-vertex-array 0))

(define (draw)
  (gl-clear-color 0.10 0.12 0.20 1.0)
  (gl-clear gl-color-buffer-bit)

  (program-use program)
  (gl-bind-vertex-array vao)
  (gl-draw-elements gl-triangles 6 gl-unsigned-short 0)
  (gl-bind-vertex-array 0))

(define-values (frame canvas)
  (make-window #:title "04 纹理"
               #:init init
               #:draw draw))
(send frame show #t)

;; ------------------------------------------------------------
;; 试试看（改完重跑）：
;;   · 把 UV 的 1.0 改成 2.0 → 纹理平铺 2×2（REPEAT 生效）
;;   · gl-texture-wrap-s 改成 gl-clamp-to-edge → 超出部分拉边缘像素
;;   · mag-filter 改成 gl-nearest → 放大时看到方块像素（不插值）
;;   · 去掉 gl-generate-mipmap → 画面变黑（用了 mipmap 过滤却没生成）
;;
;; 换成真实图片：可以用 racket/draw 读文件（read-bitmap + get-argb-pixels），
;; 拿到 RGBA 字节后同样喂给 gl-tex-image-2d。
;; ============================================================

试试看

  1. 把 UV 里的 1.0 改成 2.0：纹理平铺成 2×2（REPEAT 生效）。
  2. gl-texture-wrap-s 改成 gl-clamp-to-edge：超出部分拉边缘像素，接缝消失。
  3. mag-filter 改成 gl-nearest：放大时看到方块像素，不再插值。
  4. 删掉 gl-generate-mipmap：画面变黑——用了 mipmap 过滤却没生成，正好撞上 4.5 那个坑。
  5. 把 mix 的 0.35 改成 0.0 或 1.0：两张图各自独占画面，正好是两个极端。
  6. 把 mix 的 t 换成 (vx (texture u-overlay v-uv))：拿径向渐变的 r 当掩码，亮的地方取 overlay、暗的地方取棋盘。

小结

概念 一句话
纹理对象 显存里的一块图：texture-new 生成 id、gl-bind-texture 设为当前、gl-tex-image-2d 上传像素
UV 坐标 顶点属性告诉 GPU 每个角取图的哪里：(0,0) 是一角、(1,1) 是对角；插值后逐像素采样
环绕 wrap UV 超出 0..1 时：gl-repeat 平铺、gl-clamp-to-edge 拉边缘、gl-mirrored-repeat 镜像重复
过滤 filter mag 管放大、min 管缩小；gl-nearest 取最近像素，gl-linear 取周围 4 个的加权平均
mipmap 一串边长减半的副本，缩小采样时用；用了带 mipmap 的过滤就必须 gl-generate-mipmap
纹理单元与 sampler-2d sampler-2d 的值是槽号：gl-active-texture 选槽、gl-bind-texture 绑纹理、uniform-set! loc 'sampler-2d n 把槽号告诉采样器
多纹理与 mix 多张图各占一个纹理单元，采样器用槽号区分；mix(a, b, t) = a*(1-t) + b*t 把两次采样结果按比例混起来
