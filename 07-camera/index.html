相机

本节目标：把 06 课"用 m-translate 凑出来的 view"换成真正的相机——给定 eye（相机在哪）、center（看向哪）、up（头顶朝哪）三个值，用 m-look-at 算出 view 矩阵，再让相机绕世界原点转圈。跑起来应该看到十个棋盘立方体，镜头绕着它们转，任何时刻都是斜侧角度看过去。7.6 把相机交到键盘上，并用按键状态做到真正的连续移动。

$ racket 07-camera/camera.rkt

计算位置look-at / perspective 在 CPU 算，camera 的 eye/target/up 由 CPU 每帧更新；GPU 只负责对每个顶点乘 view/proj。替代方案是 CPU 预变换顶点，但相机一动就要重传（见 R2）。

7.1 相机是什么

顶点最后要过三道矩阵：model 把物体摆进世界、view 把世界换进观察空间、projection 把观察空间里的视锥压成 NDC（06 课讲的就是这三段串联）。这一课只动中间那一道。

观察空间（也叫相机空间）的定义是：以相机为原点、相机朝 -z 看的坐标系。它和别的坐标系没有本质区别，只是坐标轴跟着相机走——+y 是头顶方向、+x 是相机的右手边、相机看向 -z（跟 OpenGL 默认的"相机朝 -z"对上了）。view 矩阵干的活就是：把世界里的一个点，换算成"在相机眼里它长在哪"。

06 课的 view 只有一行凑合：(m-translate (vec-3 0.0 0.0 -3.0))——把整个世界往后推 3 格。这看着像"移动物体"，其实是在说"相机在原点、朝 -z、离物体 3 格远"：把世界推到 -3，和把相机挪到 +3 是一回事。

这个写法有两个死结：相机位置只能是"原点加上 z 轴上某一段"，朝向只能是 -z。想让相机站到斜侧去看，就得反过来把整个世界转到合适的角度——相机想动，动的是世界，越写越绕。真正的相机要能回答三个问题：

输入 含义
eye 相机自己在世界里的位置
center 相机看向的那个点
up 世界里的"上"大致是哪个方向，用来定头顶

lib/matrix.rkt 里的 m-look-at 就是吃这三个值、吐出 view 矩阵的函数。下一节把它的推导走一遍。

7.2 look-at 的三基推导

相机坐标系要三个互相垂直的单位向量当轴。我们从 eye、center、up 三个点把它们造出来：

  1. f（前向）：相机看向哪，就是 center - eye 这个方向，归一化成单位长度——f = normalize(center - eye)。这条最直观：两点的连线。
  2. s（右向）：相机的右手边要和 f、还要和世界上给的 up 都垂直，那就叉乘——s = normalize(f × up)。叉乘的结果同时垂直于两个输入，方向由右手法则定：拇指从 f 卷向 up，s 指出来的那一侧就是相机的右手边。
  3. u（头顶）：f 和 s 已经垂直了，再叉一次就得到第三个轴——u = s × f。注意顺序是 s × f 而不是 f × s，反了 u 就指向脚底。这样 u 也垂直于前两个，三个轴两两正交。

三个容易卡住的点：

  • 为什么 up 是输入，却不能直接当 u？ up 只是提示"头顶大概朝哪"，我们不要求它和 f 垂直（人手给方向时也给不准）；叉乘加归一化会把真正垂直的那个方向算出来。
  • 为什么 u 不用归一化？ s 和 f 是互相垂直的单位向量，两个垂直单位向量的叉乘长度正好是 1（夹角 90°，sin 90° = 1），所以 s × f 天然是单位向量。
  • 为什么相机坐标系的 z 轴是 -f 而不是 f？ OpenGL 约定相机朝着 -z 看，所以"相机看过去的方向"在相机坐标里是负 z；f 指的方向对应的就是 -z 轴。

7.3 view 矩阵长什么样

拿到 s、u、f，view 矩阵就是"把世界搬进相机坐标"这个动作本身。拆成两步看：

  1. 旋转：把世界里的 s、u、-f 三个方向分别对齐到相机坐标系的 x、y、z 轴上。矩阵的前三列就装这三个方向的分量。
  2. 平移：相机在相机坐标系里应该在原点，所以再减掉 eye。第四列那三个 -dot(轴, eye) 就是"先旋转、再减 eye"合起来的结果——旋转部分正交，逆等于转置，位移那一项就化成了基与 eye 的点积取负。

所以 m-look-at 从头到尾没有求逆矩阵，它直接照着这两步把矩阵写出来，实现只有四行：

lib/matrix.rkt：m-look-at源码 ↗
;; 视图矩阵：把"世界坐标"换成"相机坐标"，等价于把整个世界搬到相机眼前——
;; 相机在 eye 看向 center、以 up 定头顶方向，原点就落到相机上、-z 指向 center。
;; f 是相机前向、s 是右向、u 是头顶方向（三者正交）；位移那列把 eye 抹掉。
(define (m-look-at eye center up)
  (define f (vnormalize (vsub center eye)))
  (define s (vnormalize (vcross f up)))
  (define u (vcross s f))
  (mat-4 (vec-4 (vx s) (vx u) (- (vx f)) 0.0)
        (vec-4 (vy s) (vy u) (- (vy f)) 0.0)
        (vec-4 (vz s) (vz u) (- (vz f)) 0.0)
        (vec-4 (- (vdot s eye)) (- (vdot u eye)) (vdot f eye) 1.0)))

对着图 7-1 读这四列：第一列 (vx s) (vx u) (- (vx f)) 0.0 装的是 s、u、-f 的 x 分量，第二、三列装 y、z 分量，最后一列 (- (vdot s eye)) (- (vdot u eye)) (vdot f eye) 1.0 是位移，w 补 1。整张矩阵把相机坐标系的三个轴排成行、把 eye 挪到原点——正是"世界 → 相机"。

关键点06 课那行凑合的 view，其实是 look-at 的特例：m-look-at (vec-3 0.0 0.0 3.0)（eye 在 z 轴 3 处）、center 取原点、up 取 (vec-3 0.0 1.0 0.0)，算出来与 m-translate (vec-3 0.0 0.0 -3.0) 逐元素相等——16 个数一个个比较全是 #t（实测；其中几个是 -0.0，数值上等于 0.0）。相机沿 z 轴站好、朝 -z 看，look-at 就退化成"把世界推远"，两条路说的是同一件事。

7.4 绕圈动画

相机"会动"这件事没有魔法：eye 每帧算一次，view 就每帧重算，然后照常上传。让 eye 在一个圆上走，就是绕圈：

07-camera/camera.rkt：算 eye、view 和 proj源码 ↗
  ;; ---- 相机：绕着世界原点转圈 ----
  ;; eye 在半径 3、高 1.2 的圆上走：t 每秒转 0.5 弧度，转一圈约 12.6 秒。
  ;; y 固定 1.2 是让相机略高于目标（原点），于是有一点俯视感，看得到立方体顶面。
  (define t (/ (current-inexact-monotonic-milliseconds) 1000.0))
  (define eye (vec-3 (* 3.0 (cos (* t 0.5))) 1.2 (* 3.0 (sin (* t 0.5)))))
  ;; 每帧重算：eye 在动，view 就得跟着动。
  ;; center 是相机看的目标；up 只说"头顶朝哪"，长度无所谓（look-at 会归一化）。
  (define view (m-look-at eye (vec-3 0.0 0.0 0.0) (vec-3 0.0 1.0 0.0)))

  ;; 投影同 06：竖直视场 45°、aspect 与窗口同源、近远平面 0.1 / 100。
  (define proj (m-perspective (degrees->radians 45.0) aspect 0.1 100.0))

几处细节：

  • eye 的 x、z 分别取 cos、sin 乘半径 3，画出来就是一个半径 3 的水平圆；y 固定 1.2，所以相机始终比目标高一点，带一点俯视，能看到立方体的顶面。
  • (* t 0.5) 里的 0.5 是转速：t 是秒，角速度每秒 0.5 弧度，转一圈约 12.6 秒。想让镜头转快点就调这个数。
  • center 是相机看的目标，这里固定世界原点；up 写世界的"上" (0,1,0)。up 只提供方向、长度不影响结果——look-at 内部会归一化。
  • 投影那行和 06 课完全一样：竖直视场 45°、aspect 与窗口宽高同源（aspect 由 win-w / win-h 算出来，改窗口尺寸不会对不上）、近平面 0.1、远平面 100。

上传的策略也跟着变：view 和 projection 整帧只有一份（十个立方体共用），在循环外传一次就够；model 每个立方体各不相同，只能在循环里逐个传。（这一节的相机只会沿一条写死的圆绕圈——想让它听键盘自己走，见 7.6。）

7.5 up 向量与退化

回头看 s 的算法：s = normalize(f × up)。叉乘有个性质——两个向量平行时结果就是零向量。所以当 f 与 up 平行，也就是相机正对着脚下或正对着头顶看时，f × up = 0，而归一化零向量是没有定义的。

坑零向量没有方向，归一化它得到的是 NaN：GLSL 的 normalize 就是如此，顶点坐标一旦变成 NaN，整个画面什么都不剩。本教程的 lib/matrix.rkt 里 vnormalize 更直接——遇到零向量就抛错 vec-normalize: 零向量不能归一化，于是在 draw 里每帧中断，立方体一个也画不出来，终端每秒刷几十条同样的消息（实测：8 秒里 stderr 涨到 270 KB）。标准 GL 行为也是"崩"，只是崩在 GPU 里、表现为画面全黑。

所以绕圈的 y 不能走到让 eye 和 center 的连线竖直的位置——本课半径 3、y 固定 1.2，f 永远斜着，撞不上。真要做垂直俯视图，得换一个跟 f 不平行的 up，比如 (vec-3 0.0 0.0 1.0)：这时"上"变成世界的 +z，画面会跟着"躺倒"（下面试试看里就有这一条）。

7.6 自由相机：按键状态 + 连续移动

7.4 的 eye 是一条写死的圆——相机只能绕原点转，走不了、也转不了头。这一节把它交到键盘手上：WASD 前后左右平移，← → 转头、↑ ↓ 抬头低头。跑 racket 07-camera/camera-walk.rkt，长按 W 会立即、平滑地一直走；松开就停，W+D 还能斜着走。

输入从哪来。01 课讲过 racket/gui 是事件驱动的：没有 while 主循环，GUI 收到"该重绘了""按了键"这类消息时才回调你写的函数（见 01 课 1.6）。键盘也是这么进来的——make-window 现在提供两个回调：#:on-key 在按下时调用，#:on-key-up 在松开时调用。字母键是字符（如 #\w），方向键是符号（如 'left）。

我们不需要"每次事件走一步"，而是把事件翻译成状态：按下写入一个 held 集合，松开删除，draw 每帧读这个集合。这和 learnopengl 用 glfwGetKey 轮询"此刻哪些键正被按住"是同一件事，只是 Racket 这边由我们自己把按下/松开拼成状态。

lib/window.rkt：按下和松开分开回调源码 ↗
(define/override (on-char e)
  (define code (send e get-key-code))
  (if (eq? code 'release)
      (on-key-up (send e get-key-release-code))
      (on-key code)))

关键点事件只负责改状态，真正的移动发生在每帧的 draw 里。这样长按、松开、组合键、窗口失焦都能正确处理，也不再依赖操作系统的按键自动重复。

窗口失去焦点时要清空 held：否则按住 W 切走窗口，回来时集合里还留着 W，相机会一直往前走。lib/window.rkt 因此提供 #:on-focus；本课在失焦时 (hash-clear! held)。

走多远。移动不是"每次按键走一步"，而是每帧按 步长 = 速度 × dt 更新，dt 是这一帧距上一帧的秒数。这样速度只由 move-speed 决定，与帧率、按键重复率都无关。另一个坑：窗口卡了 5 秒再回来，dt 就是 5，一帧下去十几格、直接飞出场景——所以 dt 要钳一个上限（本课 0.1 秒）。

朝哪走。相机朝哪，用两个角就够：yaw（方位角）在地面平面里绕世界 y 轴转，决定朝东南西北哪一边；pitch（俯仰角）抬头 / 低头。两者合成前向单位向量：forward = (cos pitch · cos yaw, sin pitch, cos pitch · sin yaw)。看这个式子：sin pitch 是竖直分量，抬头就变大；cos pitch 缩着地面里的两个分量，越抬头水平分量越小、越朝上指。W/S 沿 forward 前后走，A/D 沿"右手边"横移，右手边由 right = normalize(forward × (0,1,0)) 算出来。

关键点pitch 必须钳在 ±89°，不能给到 ±90°。到 ±90° 时 forward 竖直、与 up 平行，7.5 讲的退化就回来了：f × up = 0，归一化零向量得 NaN，画面整个崩。你自己在 7.5 里撞过的那一下，真相机就靠一行钳制挡在门外。

三件事接起来，就是这三个函数：按下/松开只改 held，update-camera 每帧读状态并乘 dt。

07-camera/camera-walk.rkt：按键状态 + 每帧更新源码 ↗
;; 按下写入、松开删除
(define held (make-hash))
(define (held? key) (hash-has-key? held key))
(define (on-key-down key)
  (when (memq key move-keys) (hash-set! held key #t)))
(define (on-key-up key)
  (when (memq key move-keys) (hash-remove! held key)))

;; 窗口失焦时清空，避免粘键
(define (on-focus on?)
  (unless on? (hash-clear! held)))

;; 每帧：先转身，再按新朝向平移
(define (update-camera)
  (define now (current-inexact-monotonic-milliseconds))
  (define dt (min 0.1 (/ (- now last-frame-ms) 1000.0)))
  (set! last-frame-ms now)
  (define turn (* turn-speed dt))
  (when (held? 'left)  (set! yaw (- yaw turn)))
  (when (held? 'right) (set! yaw (+ yaw turn)))
  (when (held? 'up)    (set! pitch (min pitch-limit (+ pitch turn))))
  (when (held? 'down)  (set! pitch (max (- pitch-limit) (- pitch turn))))
  (define fwd (camera-forward))
  (define right (camera-right))
  (define step (* move-speed dt))
  (when (held? #\w) (set! pos (vadd pos (vmul fwd step))))
  (when (held? #\s) (set! pos (vsub pos (vmul fwd step))))
  (when (held? #\a) (set! pos (vsub pos (vmul right step))))
  (when (held? #\d) (set! pos (vadd pos (vmul right step)))))

;; draw 开头调用
(update-camera)

而 forward 是这么从两个角算出来的：

07-camera/camera-walk.rkt：欧拉角算 forward源码 ↗
;; ------------------------------------------------------------
;; 三、欧拉角：由 yaw / pitch 算出 forward 与 right
;; ------------------------------------------------------------
;; 把朝向拆成两个角来看：
;;   yaw   在地面平面里转（绕世界 y 轴），决定朝东南西北哪边
;;   pitch 抬头 / 低头，决定朝上看还是朝下看
;; 两个角一合成就是前向单位向量：
;;   forward = (cos pitch · cos yaw, sin pitch, cos pitch · sin yaw)
;; cos pitch 同时缩着地面里的两个分量：越抬头，水平分量越小、竖直分量 sin pitch 越大。
(define (camera-forward)
  (vec-3 (* (cos pitch) (cos yaw))
        (sin pitch)
        (* (cos pitch) (sin yaw))))

;; right 是相机的右手边：forward 与世界的"上" (0,1,0) 叉乘再归一化。
;; 用世界的上而不是相机的 up，是因为 yaw 只在地面平面里转——这样 right 永远躺在
;; 地面上，横移（A/D）才不会把人带得上下漂。
(define (camera-right)
  (vnormalize (vcross (camera-forward) (vec-3 0.0 1.0 0.0))))

把相机状态（pos / yaw / pitch）、上面这段输入，再配上 7.4 那套每帧重算 view / proj 的 draw，就是一架完整的自由相机。完整代码在 07-camera/camera-walk.rkt：

07-camera/camera-walk.rkt源码 ↗
#lang glsl-opengl
;; ============================================================
;; 07 · 相机（自由相机）：按键状态 + 连续移动
;; 运行：racket 07-camera/camera-walk.rkt
;; 同课对照：07-camera/camera.rkt（相机绕圈版）
;; ============================================================
;; 自由相机 = 三件事：
;;   ① 输入      #:on-key 记录"按下"，#:on-key-up 记录"松开"，维护一个 held 集合
;;   ② 每帧      draw 里读 held 集合，按 dt 更新相机位置/朝向
;;   ③ 朝向      yaw / pitch 两个欧拉角合成 forward
;; 不依赖系统"按键自动重复"：长按立即连续走，W+D 可以斜走，松开明确停止。
;; 这就是 learnopengl 用 glfwGetKey 轮询"哪些键正被按住"的等价物，
;; 只不过 Racket 这边是事件推送，我们自己把按下/松开拼成状态。

(require racket/class
         racket/gui                     ; timer%
         racket/math                    ; degrees->radians
         "../lib/window.rkt"
         "../lib/matrix.rkt")           ; m-look-at / m-translate / m-rotate-x / m-perspective

;; ------------------------------------------------------------
;; 一、窗口尺寸与 aspect
;; ------------------------------------------------------------
(define win-w 800)
(define win-h 600)
;; aspect 必须和窗口实际的宽高比一致，否则画面被拉伸。它做成可变的：窗口被拖成别的
;; 比例时，下面 #:on-size 回调会把它重算（06 课没处理的这个点，在这里补上）。
(define aspect (/ win-w win-h))

;; ------------------------------------------------------------
;; 二、相机状态（模块级、可变）
;; ------------------------------------------------------------
;; pos   相机在世界里的位置
;; yaw   方位角：绕世界 y 轴、在地面平面里转，以世界 +x 为 0、往 +z 一侧增加
;; pitch 俯仰角：抬头为正、低头为负
;; 两个角都用弧度。yaw 起步取 -90°：这时 forward 正好落在 -z 上、朝着原点那堆立方体
;; （公式见第三节；learnopengl 的相机初始朝向也是 -z）。
(define pos (vec-3 0.0 0.0 3.0))
(define yaw (- (/ pi 2.0)))
(define pitch 0.0)

;; 上一次更新相机状态的时刻（毫秒）。每帧 draw 里用它算 dt。
(define last-frame-ms (current-inexact-monotonic-milliseconds))

;; 当前正被按住的键：key -> #t。
;; 按下时写入，松开时删除；draw 每帧只看这个集合，不再依赖系统自动重复。
(define held (make-hash))
(define (held? key) (hash-has-key? held key))
(define (press-key! key) (hash-set! held key #t))
(define (release-key! key) (hash-remove! held key))

;; 每步的基准量：平移每秒几格、转每秒几弧度。真正走多远还要乘 dt（第四节）。
(define move-speed 2.5)
(define turn-speed 1.5)

;; pitch 两端钳在 ±89°。为什么不给 ±90°：到 ±90° 时 forward 竖直、与 up 平行，
;; look-at 里的 f × up 就退化成零向量，归一化它得 NaN，画面整个崩——7.5 让读者亲手
;; 撞过一次的退化，真相机就靠这一行把它挡在门外。
(define pitch-limit (degrees->radians 89.0))

;; ------------------------------------------------------------
;; 三、欧拉角：由 yaw / pitch 算出 forward 与 right
;; ------------------------------------------------------------
;; 把朝向拆成两个角来看：
;;   yaw   在地面平面里转（绕世界 y 轴），决定朝东南西北哪边
;;   pitch 抬头 / 低头，决定朝上看还是朝下看
;; 两个角一合成就是前向单位向量：
;;   forward = (cos pitch · cos yaw, sin pitch, cos pitch · sin yaw)
;; cos pitch 同时缩着地面里的两个分量：越抬头，水平分量越小、竖直分量 sin pitch 越大。
(define (camera-forward)
  (vec-3 (* (cos pitch) (cos yaw))
        (sin pitch)
        (* (cos pitch) (sin yaw))))

;; right 是相机的右手边：forward 与世界的"上" (0,1,0) 叉乘再归一化。
;; 用世界的上而不是相机的 up，是因为 yaw 只在地面平面里转——这样 right 永远躺在
;; 地面上，横移（A/D）才不会把人带得上下漂。
(define (camera-right)
  (vnormalize (vcross (camera-forward) (vec-3 0.0 1.0 0.0))))

;; ------------------------------------------------------------
;; 四、键盘输入：按下/松开维护 held，draw 每帧更新
;; ------------------------------------------------------------
;; Racket 的键盘是事件推送：按下一次送一次，松开一次送一次。
;; 我们不需要"每次事件走一步"，而是把事件翻译成状态：
;;   #:on-key     → (hash-set! held key #t)
;;   #:on-key-up  → (hash-remove! held key)
;; 然后 draw 每帧看 held 里有哪些键，乘 dt 更新相机。
;; 这样长按、组合键（W+D）、松开都自然工作，不依赖操作系统的自动重复。
(define move-keys (list #\w #\s #\a #\d 'left 'right 'up 'down))

(define (on-key-down key)
  (when (memq key move-keys)
    (press-key! key)))

(define (on-key-up key)
  (when (memq key move-keys)
    (release-key! key)))

;; 窗口失去焦点时清空 held：否则按住 W 切走窗口，回来时 held 里还留着 W，
;; 相机会一直往前走（粘键）。
(define (on-focus on?)
  (unless on?
    (hash-clear! held)))

;; draw 每帧调用一次：先算 dt，再按 held 更新位置/朝向。
(define (update-camera)
  (define now (current-inexact-monotonic-milliseconds))
  (define dt (min 0.1 (/ (- now last-frame-ms) 1000.0)))
  (set! last-frame-ms now)

  ;; 先转身，再按新朝向平移：按着 W + ← 时会边走边转。
  (define turn (* turn-speed dt))
  (when (held? 'left)  (set! yaw (- yaw turn)))
  (when (held? 'right) (set! yaw (+ yaw turn)))
  (when (held? 'up)    (set! pitch (min pitch-limit (+ pitch turn))))
  (when (held? 'down)  (set! pitch (max (- pitch-limit) (- pitch turn))))

  (define fwd (camera-forward))
  (define right (camera-right))
  (define step (* move-speed dt))
  (when (held? #\w) (set! pos (vadd pos (vmul fwd step))))
  (when (held? #\s) (set! pos (vsub pos (vmul fwd step))))
  (when (held? #\a) (set! pos (vsub pos (vmul right step))))
  (when (held? #\d) (set! pos (vadd pos (vmul right step)))))

;; 五、棋盘纹理（同 04 课：用代码生成，不依赖图片文件）
;; ------------------------------------------------------------
(define tex-size 64)
(define tex-cell 8)

(define (make-checker-texture size cell)
  (define px (make-u8-array (* size size 4) 255))
  (for* ([y (in-range size)] [x (in-range size)])
    (define on? (even? (+ (quotient x cell) (quotient y cell))))
    (define i (* (+ (* y size) x) 4))
    (define r (if on? 230 40))
    (define g (if on? 140 70))
    (define b (if on? 60 130))
    (u8-array-set! px i r)
    (u8-array-set! px (+ i 1) g)
    (u8-array-set! px (+ i 2) b)
    (u8-array-set! px (+ i 3) 255))          ; alpha 不透明
  px)

;; ------------------------------------------------------------
;; 六、着色器：三个矩阵串起来（同 camera.rkt）
;; ------------------------------------------------------------
;; 顶点连着过三道变换，写成矩阵就是从右往左乘：
;;   model：把单位立方体摆到世界里的某处
;;   view ：把世界换进相机坐标——这一次它由 pos / yaw / pitch 算出来
;;   proj ：把相机看到的视锥投影到 NDC
(define vert-src
  (glsl (version 330 core)
        (layout (location 0) in vec-3 a-pos)
        (layout (location 1) in vec-2 a-uv)
        (uniform mat-4 u-model)
        (uniform mat-4 u-view)
        (uniform mat-4 u-proj)
        (out vec-2 v-uv)
        (define (main) void
          (set! gl-position (* u-proj (* u-view (* u-model (vec-4 a-pos 1.0)))))
          (set! v-uv a-uv))))

(define frag-src
  (glsl (version 330 core)
        (in vec-2 v-uv)
        (uniform sampler-2d u-tex)
        (out vec-4 frag-color)
        (define (main) void
          (set! frag-color (texture u-tex v-uv)))))

;; ------------------------------------------------------------
;; 七、立方体数据：24 个顶点 + 36 索引 + 位置表（同 camera.rkt）
;; ------------------------------------------------------------
;; 立方体 6 个面、每面 4 个角，共 24 个顶点。8 个角点本来可以共用，
;; 但每个面都要贴自己完整的一张纹理，UV 各不相同，所以按面拆开。
;; 尺寸 ±0.5（边长 1），index 每面 6 个（两个三角形），共 36 个。
(define vertex-data
  (concat-vecs
   ;; 后面 z = -0.5
   (vec-3 -0.5 -0.5 -0.5) (vec-2 0.0 0.0)
   (vec-3  0.5 -0.5 -0.5) (vec-2 1.0 0.0)
   (vec-3  0.5  0.5 -0.5) (vec-2 1.0 1.0)
   (vec-3 -0.5  0.5 -0.5) (vec-2 0.0 1.0)
   ;; 前面 z = +0.5
   (vec-3 -0.5 -0.5  0.5) (vec-2 0.0 0.0)
   (vec-3  0.5 -0.5  0.5) (vec-2 1.0 0.0)
   (vec-3  0.5  0.5  0.5) (vec-2 1.0 1.0)
   (vec-3 -0.5  0.5  0.5) (vec-2 0.0 1.0)
   ;; 左面 x = -0.5
   (vec-3 -0.5  0.5  0.5) (vec-2 1.0 0.0)
   (vec-3 -0.5  0.5 -0.5) (vec-2 1.0 1.0)
   (vec-3 -0.5 -0.5 -0.5) (vec-2 0.0 1.0)
   (vec-3 -0.5 -0.5  0.5) (vec-2 0.0 0.0)
   ;; 右面 x = +0.5
   (vec-3  0.5  0.5  0.5) (vec-2 1.0 0.0)
   (vec-3  0.5  0.5 -0.5) (vec-2 1.0 1.0)
   (vec-3  0.5 -0.5 -0.5) (vec-2 0.0 1.0)
   (vec-3  0.5 -0.5  0.5) (vec-2 0.0 0.0)
   ;; 底面 y = -0.5
   (vec-3 -0.5 -0.5 -0.5) (vec-2 0.0 1.0)
   (vec-3  0.5 -0.5 -0.5) (vec-2 1.0 1.0)
   (vec-3  0.5 -0.5  0.5) (vec-2 1.0 0.0)
   (vec-3 -0.5 -0.5  0.5) (vec-2 0.0 0.0)
   ;; 顶面 y = +0.5
   (vec-3 -0.5  0.5 -0.5) (vec-2 0.0 1.0)
   (vec-3  0.5  0.5 -0.5) (vec-2 1.0 1.0)
   (vec-3  0.5  0.5  0.5) (vec-2 1.0 0.0)
   (vec-3 -0.5  0.5  0.5) (vec-2 0.0 0.0)))

(define indices
  (u16-array 0 3 2   2 1 0          ; 后面
             4 5 6   6 7 4          ; 前面
             8 9 10  10 11 8        ; 左面
             12 14 13 14 12 15      ; 右面
             16 17 18 18 19 16      ; 底面
             20 22 21 22 20 23))    ; 顶面

;; 十个立方体在世界里的位置（同 camera.rkt 的散布法：近处零星几个、远处一大片）。
(define cube-positions
  (list (vec-3  0.0  0.0   0.0)
        (vec-3  2.0  5.0 -15.0)
        (vec-3 -1.5 -2.2  -2.5)
        (vec-3 -3.8 -2.0 -12.3)
        (vec-3  2.4 -0.4  -3.5)
        (vec-3 -1.7  3.0  -7.5)
        (vec-3  1.3 -2.0  -2.5)
        (vec-3  1.5  2.0  -2.5)
        (vec-3  1.5  0.2  -1.5)
        (vec-3 -1.3  1.0  -1.5)))

(define program #f)
(define vao #f)
(define texture #f)

(define (init)
  (set! program (build-program (gl-vertex-shader vert-src)
                               (gl-fragment-shader frag-src)))

  ;; ---- 棋盘纹理（同 04 课）----
  (set! texture (texture-new))
  (gl-bind-texture gl-texture-2d texture)
  (gl-tex-parameter-i gl-texture-2d gl-texture-wrap-s gl-repeat)
  (gl-tex-parameter-i gl-texture-2d gl-texture-wrap-t gl-repeat)
  (gl-tex-parameter-i gl-texture-2d gl-texture-min-filter gl-linear-mipmap-linear)
  (gl-tex-parameter-i gl-texture-2d gl-texture-mag-filter gl-linear)
  (gl-tex-image-2d gl-texture-2d 0 gl-rgba tex-size tex-size 0
                   gl-rgba gl-unsigned-byte (make-checker-texture tex-size tex-cell))
  (gl-generate-mipmap gl-texture-2d)

  (program-use program)
  (uniform-set! (uniform-location program "u_tex") 'sampler-2d 0)
  (gl-active-texture gl-texture0)
  (gl-bind-texture gl-texture-2d texture)

  ;; ---- VAO / VBO / EBO ----
  (set! vao (vertex-array-new))
  (gl-bind-vertex-array vao)

  (define vbo (buffer-new))
  (gl-bind-buffer gl-array-buffer vbo)
  (buffer-upload gl-array-buffer vertex-data gl-static-draw)
  ;; 步长和偏移都从布局算出来，不写字面量。
  (define stride (shader-stride-bytes 'vec-3 'vec-2))   ; 3 + 2 = 5 个 float = 20 字节
  (define uv-offset (shader-byte-size 'vec-3))         ; 跳过位置那 3 个 float = 12 字节
  (gl-vertex-attrib-pointer 0 3 gl-float #f stride 0)
  (gl-enable-vertex-attrib-array 0)
  (gl-vertex-attrib-pointer 1 2 gl-float #f stride uv-offset)
  (gl-enable-vertex-attrib-array 1)

  (define ebo (buffer-new))
  (gl-bind-buffer gl-element-array-buffer ebo)
  (buffer-upload gl-element-array-buffer indices gl-static-draw)

  (gl-bind-vertex-array 0)

  ;; 画立体的东西就得开深度测试，否则后画的近处立方体会盖住先画的远处立方体。
  (gl-enable gl-depth-test))

(define (draw)
  ;; 每帧先根据 held 集合更新相机，再算 view / proj 并绘制。
  (update-camera)

  (gl-clear-color 0.10 0.12 0.20 1.0)
  ;; 掩码按位或：颜色和深度一起清。
  (gl-clear (bitwise-ior gl-color-buffer-bit gl-depth-buffer-bit))

  ;; ---- 相机：eye 是键盘改过的 pos，看向"自己前方一格"的点 ----
  ;; center 取 pos + forward，朝哪看完全由 yaw / pitch 说了算。
  ;; up 仍是世界的 (0,1,0)：相机不侧倾，头顶永远朝世界正上方。
  (define view (m-look-at pos (vadd pos (camera-forward)) (vec-3 0.0 1.0 0.0)))

  ;; 投影同 06：竖直视场 45°、aspect 跟着窗口（#:on-size 同步）、近远平面 0.1 / 100。
  (define proj (m-perspective (degrees->radians 45.0) aspect 0.1 100.0))

  (program-use program)
  (gl-bind-vertex-array vao)

  ;; view / proj 整帧只算一份，循环外上传一次；model 每个立方体不同，得在循环里传。
  (uniform-set! (uniform-location program "u_view") 'mat-4 view)
  (uniform-set! (uniform-location program "u_proj") 'mat-4 proj)

  ;; model 同 camera.rkt：先让立方体转到自己的姿态，再挪到位置；各立方体随时间自转，
  ;; 于是画面本身也一直在动（相机不动时也有重绘可看）。
  (define t (/ (current-inexact-monotonic-milliseconds) 1000.0))
  (for ([cube-pos (in-list cube-positions)])
    (define model (mat4-mul (m-translate cube-pos)
                            (mat4-mul (m-rotate-x (* t 0.5))
                                      (m-rotate-y t))))
    (uniform-set! (uniform-location program "u_model") 'mat-4 model)
    (gl-draw-elements gl-triangles 36 gl-unsigned-short 0))

  (gl-bind-vertex-array 0))

(define-values (frame canvas)
  (make-window #:title "07 相机（连续移动）"
               #:width win-w
               #:height win-h
               #:init init
               #:draw draw
               #:on-key on-key-down
               #:on-key-up on-key-up
               #:on-focus on-focus
               ;; 窗口尺寸变了 → 重设 viewport 之后回调这里，把 aspect 一起改掉
               #:on-size (lambda (cw ch) (set! aspect (/ cw ch)))))
(send frame show #t)
;; canvas 得先拿到键盘焦点才收得到按键——这行不能少，且 focus 不带参数
;; （写 (send canvas focus #t) 会报 arity 错）。
(send canvas focus)

;; 定时器只负责"每隔 16ms 请求重绘"，绘制永远发生在 draw 里（同 01 课）。
(define timer
  (new timer% [interval 16]
              [notify-callback (lambda () (send canvas refresh))]))

  (gl-tex-parameter-i gl-texture-2d gl-texture-min-filter gl-linear-mipmap-linear)
  (gl-tex-parameter-i gl-texture-2d gl-texture-mag-filter gl-linear)
  (gl-tex-image-2d gl-texture-2d 0 gl-rgba tex-size tex-size 0
                   gl-rgba gl-unsigned-byte (make-checker-texture tex-size tex-cell))
  (gl-generate-mipmap gl-texture-2d)

  (program-use program)
  (uniform-set! (uniform-location program "u_tex") 'sampler-2d 0)
  (gl-active-texture gl-texture0)
  (gl-bind-texture gl-texture-2d texture)

  ;; ---- VAO / VBO / EBO ----
  (set! vao (vertex-array-new))
  (gl-bind-vertex-array vao)

  (define vbo (buffer-new))
  (gl-bind-buffer gl-array-buffer vbo)
  (buffer-upload gl-array-buffer vertex-data gl-static-draw)
  ;; 步长和偏移都从布局算出来，不写字面量。
  (define stride (shader-stride-bytes 'vec-3 'vec-2))   ; 3 + 2 = 5 个 float = 20 字节
  (define uv-offset (shader-byte-size 'vec-3))         ; 跳过位置那 3 个 float = 12 字节
  (gl-vertex-attrib-pointer 0 3 gl-float #f stride 0)
  (gl-enable-vertex-attrib-array 0)
  (gl-vertex-attrib-pointer 1 2 gl-float #f stride uv-offset)
  (gl-enable-vertex-attrib-array 1)

  (define ebo (buffer-new))
  (gl-bind-buffer gl-element-array-buffer ebo)
  (buffer-upload gl-element-array-buffer indices gl-static-draw)

  (gl-bind-vertex-array 0)

  ;; ★一开始画立体的东西就得开深度测试：谁在前、谁被挡住由深度缓冲裁决，
  ;;   否则后画的近处立方体会盖住先画的远处立方体。
  (gl-enable gl-depth-test))

(define (draw)
  (gl-clear-color 0.10 0.12 0.20 1.0)
  ;; 掩码按位或：颜色和深度一起清。只清颜色的话，上一帧的深度值还留在缓冲里，
  ;; 这一帧的遮挡判断就全错了。
  (gl-clear (bitwise-ior gl-color-buffer-bit gl-depth-buffer-bit))

  ;; ---- 相机：绕着世界原点转圈 ----
  ;; eye 在半径 3、高 1.2 的圆上走：t 每秒转 0.5 弧度，转一圈约 12.6 秒。
  ;; y 固定 1.2 是让相机略高于目标（原点），于是有一点俯视感，看得到立方体顶面。
  (define t (/ (current-inexact-monotonic-milliseconds) 1000.0))
  (define eye (vec-3 (* 3.0 (cos (* t 0.5))) 1.2 (* 3.0 (sin (* t 0.5)))))
  ;; 每帧重算：eye 在动，view 就得跟着动。
  ;; center 是相机看的目标；up 只说"头顶朝哪"，长度无所谓（look-at 会归一化）。
  (define view (m-look-at eye (vec-3 0.0 0.0 0.0) (vec-3 0.0 1.0 0.0)))

  ;; 投影同 06：竖直视场 45°、aspect 与窗口同源、近远平面 0.1 / 100。
  (define proj (m-perspective (degrees->radians 45.0) aspect 0.1 100.0))

  (program-use program)
  (gl-bind-vertex-array vao)

  ;; view / proj 整帧只算一份，循环外上传一次；model 每个立方体不同，得在循环里传。
  ;; mat-4 是列主序的 f32vector，和 uniform 的布局一致，所以 transpose 传 #f。
  (uniform-set! (uniform-location program "u_view") 'mat-4 view)
  (uniform-set! (uniform-location program "u_proj") 'mat-4 proj)

  (for ([pos (in-list cube-positions)])
    ;; model = 平移 × 绕 x 自转 × 绕 y 自转：先让立方体转到自己的姿态，再挪到位置。
    ;; 组合顺序从右往左作用在顶点上；把平移写在右边的话，立方体会被旋转甩出去。
    (define model (mat4-mul (m-translate pos)
                            (mat4-mul (m-rotate-x (* t 0.5))
                                      (m-rotate-y t))))
    (uniform-set! (uniform-location program "u_model") 'mat-4 model)
    ;; 一个立方体 36 个索引：24 个顶点、6 个面、每面 6 个索引。
    (gl-draw-elements gl-triangles 36 gl-unsigned-short 0))

  (gl-bind-vertex-array 0))

(define-values (frame canvas)
  (make-window #:title "07 相机"
               #:width win-w
               #:height win-h
               #:init init
               #:draw draw
               ;; 窗口尺寸变了 → 重设 viewport 之后回调这里，把 aspect 一起改掉
               #:on-size (lambda (cw ch) (set! aspect (/ cw ch)))))
(send frame show #t)

;; 定时器只负责"每隔 16ms 请求重绘"，绘制永远发生在 draw 里（同 01 课）。
(define timer
  (new timer% [interval 16]
              [notify-callback (lambda () (send canvas refresh))]))

;; ------------------------------------------------------------
;; 试试看（改完重跑）：
;;   · center 改成 eye 正下方、或 up 改成 (0,0,0) → f 与 up 平行，叉积为 0，
;;     normalize 零向量得 NaN，画面整个崩掉（原因见 7.5）
;;   · 半径 3.0 改成 1.0 → 立方体群冲出视野，被近平面 0.1 裁掉
;;   · up 改成 (0,0,1) → u 轴换了个方向，画面"躺倒"
;; ============================================================

试试看

  1. 让它崩一次：把 up 改成 (vec-3 0.0 0.0 0.0)，或者把 eye 挪到目标正上方（(vec-3 0.0 3.0 0.0)），这时 f 与 up 平行、f × up = 0。跑起来什么都看不到，终端每帧一条 vec-normalize: 零向量不能归一化——这就是 7.5 说的退化。
  2. 自由相机见 7.6：跑 racket 07-camera/camera-walk.rkt，长按 W 应该立即、平滑地一直走；再按住 W+D 斜着走。把 on-key-up 里的 release-key! 注释掉，松开后相机会一直走——这就是"只记录按下、不记录松开"的粘键。
  3. 鼠标视角：canvas 还能接 on-event 拿到鼠标移动事件，把两次事件的偏移量喂给 yaw / pitch（pitch 记得再钳一下）就是第一人称的鼠标视角。思路到此，不展开代码。
  4. 把 pitch 的钳制从 ±89° 改成 ±90°：抬头到顶，forward 与 up 平行、f × up = 0，画面崩成 NaN（就是 7.5 那个退化）；改回 89° 即好。
  5. 把半径 3.0 改成 1.0：相机整个陷进立方体群中间，视角只剩眼前那个立方体的大面，其余立方体都跑到视野外（实测截图里只看得见一块被斜看的正面加一个角）。
  6. 把 up 改成 (vec-3 0.0 0.0 1.0)：画面整体"躺倒"。u 换了方向，相机坐标系的 y 轴跟着换，世界看起来就是侧翻的——它没崩，还是能画，只是"上"不再是你以为的那个上。

小结

概念 一句话
观察空间 以相机为原点、相机朝 -z 看的坐标系；view 矩阵把世界坐标换进它
f / s / u 三基 f = normalize(center - eye)、s = normalize(f × up)、u = s × f；三者正交，就是相机坐标系的 x / y / z（z 朝 -f）
view = 旋转 + 平移 前三列把 s / u / -f 对齐到 x / y / z，第四列把 eye 抹掉；不求逆矩阵，直接构造
up 退化 f 与 up 平行时 f × up = 0，归一化零向量无定义：GLSL 里是 NaN，本教程的 vnormalize 直接抛错，画面什么都画不出来
与 06 的关系 m-look-at eye 取 (0,0,3)、center 取原点、up 取 (0,1,0) 时，逐元素等于 m-translate (0,0,-3)——06 的凑合 view 是 look-at 的特例
每帧重算 eye 在动，view 就每帧重算；view / proj 全场共用传一次，model 每个物体各传一次
自由相机 #:on-key / #:on-key-up 维护 held 集合，每帧读状态并按 delta time 更新；yaw / pitch 欧拉角，pitch 钳 ±89° 挡住退化

Getting started 这一章到这里收尾：从开一扇窗口、画一个三角形，到纹理、变换、坐标系，最后把相机交到 eye / center / up 三个值手上。想组装成一个能用键盘到处走的完整场景，把 05–07 三节的代码合起来就行——变换管摆放、坐标系管投影、相机管视角；7.6 的按键状态让移动真正连续。回课程首页看目录。
