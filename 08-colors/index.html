颜色

本节目标：光照章的第一课，先把"颜色从哪来"这件事定下来——看到的颜色 = 物体色 × 光色（逐分量）。为此场景里除了被照的物体，还要摆一个灯自己的替身，两者用两个 program 画。跑起来应该看到屏幕正中一个大橙色立方体（相机正对它的正面，所以看着是一块方方正正的橙），右上角一个小的纯白立方体——那是灯。

$ racket 08-colors/colors.rkt

计算位置「物体色 × 光色」在片元着色器里逐像素做；CPU 只负责把两个颜色作为 uniform 传上去。CPU 也可以预乘成顶点色或一张颜色表，但换灯色/换物体色时要重新算。数据流：uniform → 片元乘法 → 屏幕。

8.1 光不是白色时发生什么

先做个思想实验：白光下橙色物体看起来是橙的，用绿光去照呢？答案是几乎全黑——因为它没有多少绿可以反射。

这个说法背后是一条很朴素的规则：物体自己不发光，它只是把照到身上的光反射一部分出去。反射多少，用物体色表示。本课那个橙就是 (1.0, 0.5, 0.31)，意思是"红光全反射、绿光反一半、蓝光几乎不反射"——换个说法，物体色其实是反射率。光色说的是另一件事：照过来的光里三个分量各有多少。两者逐分量相乘，就是眼睛看到的那份光：

  • 白光 (1.0, 1.0, 1.0) × 橙 (1.0, 0.5, 0.31) = (1.0, 0.5, 0.31)——还是橙的。白光乘上去等于没乘。
  • 绿光 (0.0, 1.0, 0.0) × 橙 (1.0, 0.5, 0.31) = (0.0, 0.5, 0.0)——只剩一点暗暗的绿，看上去又暗又闷。

写成公式就是逐分量相乘（不是向量点积）：

result = (L_r·O_r, L_g·O_g, L_b·O_b)

其中 L 是光色、O 是物体色。这个乘法没有方向、没有距离，只回答「有多少光被反射回来」——方向要等 09 课，距离要等 11 课。

顺带把数字和颜色对上：(1.0, 0.5, 0.31) 换成 0..255 就是 rgb(255, 128, 79)，正是本课那个橙色。三个分量分开看，就得到图 8-1 里的三条色条——光色一条、物体色一条、乘出来的结果一条。

绿光下橙物体发黑，是"逐分量相乘"的直接后果：绿光里只有 G 分量不为 0，而橙物体的绿反射率只有 0.5；R、B 两个通道那边压根没有光可反射，于是整块物体暗下去。画面上不会因为"绿光"就凭空多出绿色来。

8.2 两个 program：物体与灯

场景里只有两个立方体：被照的物体（橙）和灯自己。但这两个东西得用两个 program 画——因为它们的片元要算的事不一样。

物体的片元把两个颜色乘起来，本课全部的"物理"就在这一行：

08-colors/colors.rkt：物体片元（做乘法）源码 ↗
;; 物体的片元：本课全部的"物理"就是这一行逐分量乘法。
;; u-object-color 不是颜料，而是反射率：光里的每个分量各被反射回去多少。
;; 白光 (1,1,1) 照到橙 (1.0, 0.5, 0.31)，乘出来还是 (1.0, 0.5, 0.31)——它显橙。
(define object-frag-src
  (glsl (version 330 core)
        (uniform vec-3 u-object-color)            ; 物体本色：它反射哪些分量、各反射多少
        (uniform vec-3 u-light-color)             ; 光的颜色：照过来时各分量各有多少
        (out vec-4 frag-color)
        (define (main) void
          (set! frag-color (vec-4 (* u-object-color u-light-color) 1.0)))))

灯的片元只把光色原样输出，不做乘法：

08-colors/colors.rkt：灯片元（纯色）源码 ↗
;; 灯的片元：只把光色原样输出，不做乘法。
;; 灯是光本身，不是"被光照到的物体"。要是也乘一遍，白光乘白灯还算凑合，
;; 换成绿光乘白灯，灯自己就被调暗了——那等于说"灯也被谁照着"，是错的。
(define lamp-frag-src
  (glsl (version 330 core)
        (uniform vec-3 u-light-color)
        (out vec-4 frag-color)
        (define (main) void
          (set! frag-color (vec-4 u-light-color 1.0)))))

为什么要分两个？因为灯是光本身，不是"被光照到的物体"。如果灯的片元也跟着乘一遍，白光乘白灯还算凑合，换成绿光乘白灯，灯自己就被调暗了——那等于说"灯也被谁照着"，是错的。两个 program 的顶点着色器倒是完全一样（都只声明 location 0 的位置属性和三个矩阵），所以共用一份源码。

关键点这就是"光照模型"的最简版：看到的颜色 = 物体色 × 光色。后面每一课都是在这个乘法上逐项加东西——09 课加方向（法向与点乘）、10 课把物体色换成贴图、11 课加距离衰减与镜面高光。现在先把这条乘法钉牢。

8.3 同一个 VAO 喂两个 program

VAO 记住的是"怎么从缓冲里读出一个顶点"：哪块 VBO、取几个分量、步长多少、偏移多少、第几号槽开着。它不记这些属性要交给哪个 program——program 是另一件独立的东西。所以 draw 里换 program 只是换一组 uniform 和一段片元逻辑，顶点数据那边一个字都不用改：

08-colors/colors.rkt：draw 里换 program源码 ↗
  ;; 同一个 VAO 全程 bind 着，中间只换 program。
  (gl-bind-vertex-array vao)

  ;; ---- 物体：片元做 物体色 × 光色 ----
  (program-use object-program)
  (uniform-set! obj-u-model 'mat-4 (m-translate object-pos))
  (uniform-set! obj-u-view 'mat-4 view)
  (uniform-set! obj-u-proj 'mat-4 proj)
  (uniform-set! obj-u-object-color 'vec-3 object-color)
  (uniform-set! obj-u-light-color 'vec-3 light-color)
  (gl-draw-elements gl-triangles 36 gl-unsigned-short 0)

  ;; ---- 灯：同一个 VAO、换个 program，片元只输出光色 ----
  ;; VAO 只记"怎么从缓冲里读出一个顶点"，不记"读给哪个 program 用"，所以换了
  ;; program 连 bind 都不用重来。09 课的 VAO 会多开一个 normal 槽（location 1），
  ;; 而灯这个 program 依旧只声明 location 0——多开的属性槽在没有对应 in 的
  ;; program 里被 GL 忽略，不会报错，灯照画不误。
  (program-use lamp-program)
  ;; 灯比物体小：先缩到 0.2 倍，再搬到 lamp-pos（从右往左作用在顶点上）。
  (uniform-set! lamp-u-model 'mat-4 (mat4-mul (m-translate lamp-pos) (m-scale (vec-3 0.2 0.2 0.2))))
  (uniform-set! lamp-u-view 'mat-4 view)
  (uniform-set! lamp-u-proj 'mat-4 proj)
  (uniform-set! lamp-u-light-color 'vec-3 light-color)
  (gl-draw-elements gl-triangles 36 gl-unsigned-short 0)

连 gl-bind-vertex-array 都不用重来：全程 bind 着同一个 VAO，中间只 program-use 一次。两个 program 里都叫 u-model 的 uniform 在 GPU 上是两个槽位，所以上传前得用对应 program 查出来的位置——init 里位置是分两套存的。

到 09 课这份"共用"会有变化：那时物体的片元要算法向，VAO 得再开一个 location 1 的 normal 槽。这会弄坏灯吗？不会——灯那个 program 依旧只声明 location 0，多开的属性槽在没有对应 in 的 program 里被 GL 直接忽略，不报错、也不影响绘制，灯照画不误。VAO 和 program 各管各的，这份宽容正是状态机的常态。

完整代码

08-colors/colors.rkt，本课全部代码（直接 racket 跑）：

08-colors/colors.rkt源码 ↗
#lang glsl-opengl
;; ============================================================
;; 08 · 颜色
;; 运行：racket 08-colors/colors.rkt
;; 上一课：07-camera/camera.rkt
;; ============================================================
;; 目标：光照章的第一课，但还没有方向、没有衰减——先只回答"颜色从哪来"。
;; 一件东西看起来是什么颜色，取决于两件事：它自己是什么颜色、照它的光是什么颜色。
;; 本课全部的"物理"就是一行乘法（逐分量）：
;;     看到的颜色 = 物体色 × 光色
;; 物体色说的是"这份光里我能反射回去多少"：橙 (1.0, 0.5, 0.31) 的意思是
;; 红全反射、绿反一半、蓝几乎不反射。白光 (1,1,1) 乘上去等于没乘，所以白光下
;; 它显橙；换成绿光 (0,1,0)，三个分量里活下来的只有绿那一份，物体立刻发黑。
;; 场景里两个立方体：被照的物体（橙），和灯自己的替身（白、小方块）。
;; 它们用两个 program 画——物体的片元做乘法，灯的片元只输出光色，见下。

(require racket/class
         racket/math                     ; degrees->radians
         "../lib/window.rkt"
         "../lib/matrix.rkt")            ; m-look-at / m-perspective / m-translate / m-scale

;; ------------------------------------------------------------
;; 一、窗口尺寸与 aspect（同 06 / 07 课）
;; ------------------------------------------------------------
(define win-w 800)
(define win-h 600)
;; 投影要一个 aspect = 宽/高，必须和窗口客户区同源，否则画面会被拉伸。
(define aspect (/ win-w win-h))

;; ------------------------------------------------------------
;; 二、着色器
;; ------------------------------------------------------------
;; 顶点着色器两个 program 共用同一份源码：都只声明 location 0 的位置属性，
;; 都只要 model / view / proj 三个矩阵。两个 program 的差别全在片元那一段。
(define vert-src
  (glsl (version 330 core)
        (layout (location 0) in vec-3 a-pos)     ; 属性 0：局部坐标
        (uniform mat-4 u-model)                  ; 局部 → 世界
        (uniform mat-4 u-view)                   ; 世界 → 观察
        (uniform mat-4 u-proj)                   ; 观察 → 裁剪
        (define (main) void
          (set! gl-position (* u-proj (* u-view (* u-model (vec-4 a-pos 1.0))))))))

;; 物体的片元：本课全部的"物理"就是这一行逐分量乘法。
;; u-object-color 不是颜料，而是反射率：光里的每个分量各被反射回去多少。
;; 白光 (1,1,1) 照到橙 (1.0, 0.5, 0.31)，乘出来还是 (1.0, 0.5, 0.31)——它显橙。
(define object-frag-src
  (glsl (version 330 core)
        (uniform vec-3 u-object-color)            ; 物体本色：它反射哪些分量、各反射多少
        (uniform vec-3 u-light-color)             ; 光的颜色：照过来时各分量各有多少
        (out vec-4 frag-color)
        (define (main) void
          (set! frag-color (vec-4 (* u-object-color u-light-color) 1.0)))))

;; 灯的片元：只把光色原样输出，不做乘法。
;; 灯是光本身，不是"被光照到的物体"。要是也乘一遍，白光乘白灯还算凑合，
;; 换成绿光乘白灯，灯自己就被调暗了——那等于说"灯也被谁照着"，是错的。
(define lamp-frag-src
  (glsl (version 330 core)
        (uniform vec-3 u-light-color)
        (out vec-4 frag-color)
        (define (main) void
          (set! frag-color (vec-4 u-light-color 1.0)))))

;; ------------------------------------------------------------
;; 三、立方体数据：24 个顶点 + 36 个索引
;; ------------------------------------------------------------
;; 和 06 / 07 课是同一个立方体、同样的 24 顶点 / 36 索引（06 课解释过为什么不是
;; 8 个：每个面要摊自己的一份顶点）。区别是本课只要位置：一个顶点 12 个字节，
;; 没有 UV，也没有法向——法向要到 09 课才回来。
(define vertex-data
  (concat-vecs
   ;; 后面 z = -0.5
   (vec-3 -0.5 -0.5 -0.5)
   (vec-3  0.5 -0.5 -0.5)
   (vec-3  0.5  0.5 -0.5)
   (vec-3 -0.5  0.5 -0.5)
   ;; 前面 z = +0.5
   (vec-3 -0.5 -0.5  0.5)
   (vec-3  0.5 -0.5  0.5)
   (vec-3  0.5  0.5  0.5)
   (vec-3 -0.5  0.5  0.5)
   ;; 左面 x = -0.5
   (vec-3 -0.5  0.5  0.5)
   (vec-3 -0.5  0.5 -0.5)
   (vec-3 -0.5 -0.5 -0.5)
   (vec-3 -0.5 -0.5  0.5)
   ;; 右面 x = +0.5
   (vec-3  0.5  0.5  0.5)
   (vec-3  0.5  0.5 -0.5)
   (vec-3  0.5 -0.5 -0.5)
   (vec-3  0.5 -0.5  0.5)
   ;; 底面 y = -0.5
   (vec-3 -0.5 -0.5 -0.5)
   (vec-3  0.5 -0.5 -0.5)
   (vec-3  0.5 -0.5  0.5)
   (vec-3 -0.5 -0.5  0.5)
   ;; 顶面 y = +0.5
   (vec-3 -0.5  0.5 -0.5)
   (vec-3  0.5  0.5 -0.5)
   (vec-3  0.5  0.5  0.5)
   (vec-3 -0.5  0.5  0.5)))

;; 每个面两个三角形、6 个下标，六个面合计 36（同 06 课）。
(define indices
  (u16-array 0 3 2   2 1 0        ; 后面
             4 5 6   6 7 4        ; 前面
             8 9 10  10 11 8      ; 左面
             12 14 13  14 12 15   ; 右面
             16 17 18  18 19 16   ; 底面
             20 22 21  22 20 23)) ; 顶面

;; ------------------------------------------------------------
;; 四、场景：一个物体 + 一盏灯
;; ------------------------------------------------------------
;; 物体摆在世界原点；灯摆在它的右上方前方一点，用 0.2 倍的模型缩成小方块。
;; 相机固定站在 (0,0,3) 看向原点——本课镜头不动，重点全在颜色。
;; 灯的 z 取 0（和物体差不多深）是为了构图：灯离相机越近，越容易被画面边缘挤出去；
;; 现在它稳稳落在右上角，而物体正面在 z = +0.5、离相机更近，看着更大。
(define object-pos (vec-3 0.0 0.0 0.0))
(define lamp-pos (vec-3 1.2 1.0 0.0))
(define object-color (vec-3 1.0 0.5 0.31))      ; 物体的本色：橙
(define light-color (vec-3 1.0 1.0 1.0))        ; 光的颜色：白

(define object-program 0)
(define lamp-program 0)
(define vao 0)
;; uniform 位置是"每个 program 各有一份"的：两个 program 里都叫 u-model 的 uniform
;; 在 GPU 上是两个槽位，位置值不保证相同，所以两套各存一套、不混用。
(define obj-u-model #f)
(define obj-u-view #f)
(define obj-u-proj #f)
(define obj-u-object-color #f)
(define obj-u-light-color #f)
(define lamp-u-model #f)
(define lamp-u-view #f)
(define lamp-u-proj #f)
(define lamp-u-light-color #f)
;; 这些缓冲句柄也放在顶层：关窗时 shutdown 要能拿到（0 = 还没创建）
(define vbo 0)
(define ebo 0)

(define (init)
  ;; 同一份顶点源码，配两份不同的片元，链接出两个 program。
  (set! object-program (build-program (gl-vertex-shader vert-src)
                                      (gl-fragment-shader object-frag-src)))
  (set! lamp-program (build-program (gl-vertex-shader vert-src)
                                    (gl-fragment-shader lamp-frag-src)))

  ;; 画立体的东西就得开深度测试，否则后画的片元盖住先画的、与远近无关（06 课）。
  (gl-enable gl-depth-test)

  ;; ---- VAO / VBO / EBO ----
  ;; VAO 里只开 0 号槽：位置。两个 program 的顶点着色器都只声明 layout 0，
  ;; 所以这一个 VAO 喂给谁都对得上。
  (set! vao (vertex-array-new))
  (gl-bind-vertex-array vao)

  (set! vbo (buffer-new))
  (gl-bind-buffer gl-array-buffer vbo)
  (buffer-upload gl-array-buffer vertex-data gl-static-draw)
  ;; 只有一个属性：步长就是 vec-3 的大小、偏移 0，都从布局算出来，不写字面量。
  (gl-vertex-attrib-pointer 0 3 gl-float #f (shader-byte-size 'vec-3) 0)
  (gl-enable-vertex-attrib-array 0)

  (set! ebo (buffer-new))
  (gl-bind-buffer gl-element-array-buffer ebo)
  (buffer-upload gl-element-array-buffer indices gl-static-draw)

  (gl-bind-vertex-array 0)

  ;; 链接完把两个 program 的 uniform 位置各查一次存起来，draw 里直接用。
  (set! obj-u-model (uniform-location object-program "u_model"))
  (set! obj-u-view (uniform-location object-program "u_view"))
  (set! obj-u-proj (uniform-location object-program "u_proj"))
  (set! obj-u-object-color (uniform-location object-program "u_object_color"))
  (set! obj-u-light-color (uniform-location object-program "u_light_color"))
  (set! lamp-u-model (uniform-location lamp-program "u_model"))
  (set! lamp-u-view (uniform-location lamp-program "u_view"))
  (set! lamp-u-proj (uniform-location lamp-program "u_proj"))
  (set! lamp-u-light-color (uniform-location lamp-program "u_light_color")))

(define (draw)
  (gl-clear-color 0.10 0.12 0.20 1.0)
  ;; 颜色和深度一起擦（掩码，01 课）：只擦颜色的话，上一帧的深度还留着，
  ;; 这一帧的遮挡判断就全错了（06 课）。
  (gl-clear (bitwise-ior gl-color-buffer-bit gl-depth-buffer-bit))

  ;; 相机固定站在 (0,0,3) 看向原点，本课不移动它。proj 每帧重算，于是窗口
  ;; 被拖动时 aspect 一改，下一帧的投影就用上新值（#:on-size，见文件末尾）。
  (define view (m-look-at (vec-3 0.0 0.0 3.0) (vec-3 0.0 0.0 0.0) (vec-3 0.0 1.0 0.0)))
  (define proj (m-perspective (degrees->radians 45.0) aspect 0.1 100.0))

  ;; 同一个 VAO 全程 bind 着，中间只换 program。
  (gl-bind-vertex-array vao)

  ;; ---- 物体：片元做 物体色 × 光色 ----
  (program-use object-program)
  (uniform-set! obj-u-model 'mat-4 (m-translate object-pos))
  (uniform-set! obj-u-view 'mat-4 view)
  (uniform-set! obj-u-proj 'mat-4 proj)
  (uniform-set! obj-u-object-color 'vec-3 object-color)
  (uniform-set! obj-u-light-color 'vec-3 light-color)
  (gl-draw-elements gl-triangles 36 gl-unsigned-short 0)

  ;; ---- 灯：同一个 VAO、换个 program，片元只输出光色 ----
  ;; VAO 只记"怎么从缓冲里读出一个顶点"，不记"读给哪个 program 用"，所以换了
  ;; program 连 bind 都不用重来。09 课的 VAO 会多开一个 normal 槽（location 1），
  ;; 而灯这个 program 依旧只声明 location 0——多开的属性槽在没有对应 in 的
  ;; program 里被 GL 忽略，不会报错，灯照画不误。
  (program-use lamp-program)
  ;; 灯比物体小：先缩到 0.2 倍，再搬到 lamp-pos（从右往左作用在顶点上）。
  (uniform-set! lamp-u-model 'mat-4 (mat4-mul (m-translate lamp-pos) (m-scale (vec-3 0.2 0.2 0.2))))
  (uniform-set! lamp-u-view 'mat-4 view)
  (uniform-set! lamp-u-proj 'mat-4 proj)
  (uniform-set! lamp-u-light-color 'vec-3 light-color)
  (gl-draw-elements gl-triangles 36 gl-unsigned-short 0)

  (gl-bind-vertex-array 0))

;; ------------------------------------------------------------
;; 关窗前释放：这些句柄归调用方，不删就一直占着显存
;; ------------------------------------------------------------
;; 顺序：先解绑当前状态，再删引用方（VAO）→ 缓冲 → 纹理 → program。
;; 初始值是 0：0 不是有效对象，GL 的 delete 会忽略它（init 没跑完也能安全关窗）。
(define (shutdown)
  (gl-bind-vertex-array 0)      ; 别删正在用的
  (gl-use-program 0)
  (vertex-array-delete vao)
  (buffer-delete vbo)
  (buffer-delete ebo)
  (program-delete object-program)
  (program-delete lamp-program))

(define-values (frame canvas)
  (make-window #:title "08 颜色"
               #:width win-w
               #:height win-h
               #:init init
               #:draw draw
               ;; 窗口尺寸变化、viewport 重设之后被调用，参数是新的客户区宽高。
               #:on-size (lambda (cw ch) (set! aspect (/ cw ch)))
               #:on-close shutdown))
(send frame show #t)

;; 本课没有 timer：场景是静的、没有东西在动，就不必每 16ms 请求一次重绘（接 01 课）。
;; 窗口被遮住再露出来时，系统会让画布重绘，draw 自然会再跑一遍。
;; canvas 也用不着 focus——本课不收键盘。

试试看

  1. 把 light-color 改成 (vec-3 0.0 1.0 0.0)（纯绿光）：橙物体只剩绿分量 (0.0, 0.5, 0.0)，整个立方体明显发暗发黑——和 8.1 里那句话、图 8-1 那条色条对上了。灯的替身倒是没变暗，它是纯绿的了——因为它输出的是光色本身。
  2. 把 object-color 改成 (vec-3 1.0 1.0 1.0)：三个分量全反射，物体变成"光是什么色它就是什么色"。白光下它是白的，再配第 1 条的绿光，它就和灯一样绿。
  3. 把灯的片元也改成做乘法：给 lamp-frag-src 加一个 (uniform vec-3 u-object-color)，把输出换成 (vec-4 (* u-object-color u-light-color) 1.0)，再给灯上传一个偏暗的物体色（比如 (vec-3 0.5 0.5 0.5)）。灯自己跟着变暗——这就是它必须另起一个 program 的原因。
  4. 把 lamp-pos 改成 (vec-3 1.2 1.0 -2.0)，让灯跑到物体背后（变成屏幕右下方一个小方块）：物体的颜色一点都不变。本课的光没有方向、没有距离，物体色乘光色与灯摆在哪无关。方向要等 09 课（法向与点乘），衰减要等 11 课。

GPU 资源本节创建的 program / VAO / VBO（以及纹理）都在文件末尾的 shutdown 里用 program-delete / vertex-array-delete / buffer-delete 显式删除，由 #:on-close shutdown 在关窗时触发。为什么这些句柄 GC 管不了、为什么必须手动删，见 02 · 2.9。

小结

概念 一句话
颜色相乘模型 看到的颜色 = 物体色 × 光色（逐分量）；物体色是反射率，光色是光源各分量有多少
灯的片元 灯只输出 u-light-color、不做乘法——它是光本身，不该再被"光照"一次
双 program 与 VAO 共用 VAO 只记"怎么读顶点"、不记"给哪个 program"；换 program 后同一个 VAO 照画，多开的属性槽被没有对应 in 的 program 忽略
uniform 颜色 颜色当 vec-3 uniform 上传，改颜色不用重建 program 或 VAO，下一帧就生效
